# Stock Scout

직전 완료된 미국 정규장의 KIS 일봉으로 다음 정규장의 매수 검토 후보를 최대 5개까지 찾는 개인용 CLI입니다. 보고서에서 기준 종가, 선정 근거, 관찰 기간, 주요 위험을 확인할 수 있습니다. 주문과 소수점 거래 가능 여부는 증권사에서 직접 확인하세요.

## 시작하기

1. [실행 환경과 인증을 준비하세요](docs/getting-started.md).
2. [매수 후보 보고서를 실행하세요](docs/buy-candidates.md#준비와-실행). 필요한 데이터가 준비된 뒤 다음 정규장이 열리기 전에 실행합니다.
3. [결과와 실패를 구분하세요](docs/buy-candidates.md#보고서-확인). 정상적으로 분석을 마친 뒤의 후보 없음과 자료 부족으로 끝난 실행은 서로 다른 결과입니다.

첫 버전의 한국 낮 통합 실행에서는 완료 일봉을 사용한 정상 후보 없음 보고서를 확인했습니다. 후보가 있는 보고서의 실제 실행, 한국 낮 전체의 가용성, 추천 품질은 미검증입니다. [첫 버전 인수 기록](docs/first-version-acceptance.md#2026-11-03-한국-낮-통합-실행)
