# 한국 낮의 종가 기반 매수 후보 판단

[#237](https://github.com/mochafreddo/stock-scout/issues/237)과 열린 후속 이슈에 반영할 2026-10-21 설계 인터뷰의 합의다. 매수 후보 판단만 다루며 매도·유지 판단, 보유 내역 분석, 토스증권 API 연동은 후속 범위로 둔다. 이 문서는 설계 합의이며 구현·실연동 완료의 근거가 아니다.

## 이용 흐름

사용자는 한국 낮에 직전 완료 정규장의 종가 기준 데이터로 최대 5개의 매수 검토 후보 또는 후보 없음을 확인하고, 토스증권에서 소수점 거래 가능 여부를 확인한 뒤 단순 소수점 매수를 직접 예약한다. 조건부·전략적 주문 예약을 사용할 수 없다는 사용자 설명을 이용 조건으로 삼는다. 토스증권의 접수 시간·체결 방식·대상 종목을 독립 검증한 결과는 아니며 서비스의 분석 지원 시간과 구분한다.

## Q8: 실행 가능 시간

뉴욕 현지 거래일 자정 제한을 없앤다. 직전 정규장 종료 후 필요한 데이터가 준비된 때부터 다음 정규장 개장 전까지 실행한다. 주말·휴장일에도 검증된 다음 정규장을 판단 대상으로 표시한다. 장중에는 다음 세션을 골라 우회하지 않고 실행을 거부한다. 시작 시각과 출력 직전에 지원 시간을 확인하며 실행 도중 대상 정규장이 개장하면 실패한다.

공식 일정으로 직전 완료 정규장인 데이터 기준 세션과 다음 정규장인 판단 대상 세션을 각각 확인한다. NAS·NYS·AMS의 공통 세션과 시간대·서머타임·휴장·조기 폐장·별도 변경 공지 검증, 필요한 인접 연도 자료와 실패 계약은 유지한다. 실제 분석 지원 시간은 KIS 데이터 준비 상태를 검증한 뒤 #251에서 확정한다.

## Q9: 종가 기준 데이터

직전 완료 정규장까지의 종가·일봉·거래량 등 필요한 과거 데이터로 판단한다. 종가 한 값만 사용하는 뜻으로 제한하지 않으며 진행 중인 세션의 수치는 섞지 않는다. 조회 시각, 자료 기준일과 데이터 기준 세션을 구분한다. 종가의 정규장 범위·단위·수정주가 여부와 필요한 과거 기간을 검증한다.

NAS·NYS·AMS의 거래량·거래대금 여섯 순위 자동 탐색과 원래 순위 보존, 상위 N개 후 제외·중복 제거 및 미보충 정책을 유지한다. 순위도 직전 완료 정규장 기준임을 입증해야 한다. 불가능하거나 불명확하면 차단 조건을 기록하고 탐색 방식 변경을 별도로 결정한다. 현재 순위를 탐색용으로 사용하며 검증을 생략하는 방식은 합의하지 않았다.

#239·#245의 후보군 조회는 매수 후보 선정·추천을 수행하지 않으며 증권 유형 판단은 검증된 #250의 조회 근거 기반 판단 경로를 재사용한다. 기존 LLM 호출의 일괄 제외 문구는 이 구분에 맞게 정리한다. 구체적인 연결 방식은 후속 구현에서 정하며 별도 범용 분류기나 새 공급자를 추가하지 않는다.

## Q10: 소수점 거래 가능 여부

보통주·적격 ADR이라는 증권 유형 조건과 토스증권의 소수점 거래 가능 여부는 별개다. 첫 버전은 토스증권 API나 자동 대상 목록 수집을 추가하지 않는다. 보고서에 소수점 거래 가능 여부가 미확인임을 표시하고 사용자가 예약 전에 확인한다. 증권 유형 검증 통과를 토스증권 거래 가능 판정으로 사용하지 않는다.

## Q11: 보고서

현재 분석에 따른 매수 검토 후보 또는 후보 없음을 제시한다. 기존 선정 근거·관찰 기간과 이유·주요 위험을 유지하고 기준 종가·데이터 기준 세션·판단 대상 세션을 표시한다. 진행 중인 장의 조건 충족을 기다리는 매수 지시는 제외한다. 기준 종가는 분석 기준이며 예약 주문의 예상·보장 체결가격으로 제시하지 않는다. 이 결과의 판단 대상은 표시한 다음 정규장이며 대상 개장 이후의 새 판단으로 재사용하지 않는다.

매도·유지 판단이나 보유 종목 입력은 추가하지 않는다. 직접 주문·자동 주문·예약 등록·예약 실행·알림도 추가하지 않는다. 후보 없음, 빈 후보군, 분석 불충분, 실행 실패를 기존 계약에 따라 구분한다. 매수 금액이나 비중의 자동 산정은 이번 변경에 추가하지 않는다.

## 검증과 반영 경계

공개 검증 경계는 CLI 인수·stdout·stderr·종료 코드와 외부 HTTP 요청이다. 한국 낮의 뉴욕 자정 전후, 정규장 개폐장 경계, 주말·휴장·서머타임·인접 연도, 자료 준비 미확인·세션 불일치·종가 필드 누락, 보고서의 대상 세션과 소수점 거래 미확인 표시를 검증 대상으로 삼는다. 모의 검사와 실제 일정·KIS·구독 모델 검증은 구분한다.

이번 반영은 명세와 문서 수정이다. 기존 이슈의 완료 체크·상태와 검증 이력은 보존하며 새 조건은 미완료로 남긴다. 예전 관측을 한국 낮 지원이나 종가 기반 인수 성공으로 승격하지 않는다. 런타임 구현·실제 인증·모델 호출·주문·커밋·푸시·이슈 종료는 이번 반영에 포함하지 않는다. 리뷰 기준은 로컬 `41a4188e0413a95dc6757658c1e4d99a492f8859`와 각 이슈의 갱신 전 원문이다. Q12에서 이 범위·검증 경계·기준을 최종 확인하고 열린 이슈 11개 본문 반영을 승인받았다.
