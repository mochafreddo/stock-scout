# 첫 버전 인수 기록

2026-10-31 [#242](https://github.com/mochafreddo/stock-scout/issues/242)의 인수 검증 기록이다. 한국 낮의 최종 보고서 성공을 아직 확보하지 못했으므로 전체 인수는 미완료다. 실제 수익성·추천 성과·독립적인 의미 정확도·토스증권 거래 가능 여부를 검증한 결과가 아니다.

## 범위와 현재 계약

검토 기준과 실행 소스는 `ac46d7b4be0036abc46ac89e21d5e49344f3927d`다. 공개 검증 경계는 CLI 인수·stdout·stderr·종료 코드와 외부 HTTP다. 기존 인증과 Sol 일정·추천, Luna 유형 판단, 전체 600초·단계별 한도·유료 합산 1달러를 유지한다. 이번 범위는 실제 통합 실행 최대 1회, 기존 검사와 실패 대조, 운영 안내·인수 기록과 현재 main의 로컬 커밋이다.

#242의 한국 낮 설계를 우선하되 이후 결정으로 대체된 조건은 현재 계약을 따른다. [ADR 0011](adr/0011-ranking-discovery-and-runtime-data-readiness.md)에 따라 여섯 순위는 조회 당시의 탐색 자료이며 완료 정규장 순위라는 입증을 요구하지 않는다. 분석에는 공식 일정의 최근 20개 완료 세션 일봉을 사용한다. 일봉의 정규장 범위는 승인된 KIS 필드 운영 가정이고 수정주가를 반영하지 않는다. [ADR 0015](adr/0015-subscription-buy-candidate-report.md)의 보고서·명시적 완료 계약과 [ADR 0016](adr/0016-bounded-paid-recommendation.md)의 추천 단계 유료 전환 범위를 함께 적용한다.

## 이번 실제 실행과 실패 대조

10월 31일 22:27:25~22:30:58 KST에 승인한 통합 실행 1회를 수행했다. 212.697초 뒤 종료 코드 0, `status: no_candidates`, 빈 stderr를 확인했다. 데이터 기준 세션은 10월 30일, 판단 대상은 11월 2일이며 소스 지문은 실행 전후 일치했다. 여섯 탐색 순위의 요청·수신 시각과 출력 시각은 [선별 실행 근거](evidence/issue-242/acceptance.json)에 UTC로 기록했다.

이번 실행은 정상 빈 후보군 경로다. 여섯 순위의 INTC·QQQ·NOK·TSM·BURU·SPY 중 QQQ를 ETF로 제외하고 나머지 5종목은 유형 미확인으로 제외했다. 적격 종목과 일봉 조회는 0개다. 이전 21시대의 INTC 일봉 사용 성공을 이번 실행의 결과로 합치지 않으며, 이번 완료를 실제 일봉을 읽은 후보 선정의 근거로 삼지 않는다. 정상 빈 후보군은 기존 계약상 허용되지만 충분한 유형 조사나 유용한 후보 탐색을 입증하지 않는다.

일정 모델 요청은 1회, 유형은 요청 3회·명시적 완료 3회, 추천·별도 의미 검토는 요청 2회·명시적 완료 2회다. 전송 집계는 공식 일정 HTTP 52회·KIS 12회·발급 0회·SIWC 갱신 1회이며 유료 전환은 없었다. 성공 출력은 일정 모델의 완료 이벤트 수를 별도로 제공하지 않으므로 고정 소스의 완료 검사와 모의 실패 대조를 구분한다. 정상 출력의 `semanticReview.reliability`와 소수점 거래 상태는 계속 `unverified`다.

관련 CLI 검사 91개와 타입 검사를 통과했다. 격리 사본의 변이 10건은 명시적 완료, 개장 마감, 양수 OHLC, 필수 세션 날짜, 캐시 만료 60초 여유, 발급 300초 간격, 남은 유료 요청의 예산 확보, 1달러 상한, 의미 검토 거부, 공식 구독 소진에만 전환하는 조건을 각각 훼손했다. 같은 검사 명령은 원본에서 통과했고 각 변이에서 `AssertionError`로 실패했다. 환경·인증 파일은 사본에서 제외했으며 실제 런타임 소스는 수정하지 않았다. 이는 코드의 거부 경계가 작동한다는 검사이며 모델 의미 판단의 정확도나 공급자 오류를 실제로 재현한 결과가 아니다.

승인한 1회를 모두 사용했으며 자동 재실행하지 않았다. 한국 낮 실행, 실제 만료 복구, 실제 구독 소진·유료 통합 보고서와 청구 대조, 후보가 있는 보고서의 실연동은 수행하지 않았다. 한국 낮은 현재 실행 시간 범위 밖이고, 나머지는 이번 승인 범위의 통합 실행에서 관측되지 않았거나 별도 품질·장애 검증이다.

## 실행과 장애 대응 절차

1. [실행 준비](candidate-universe.md#실행하기)와 [KIS 인증](kis-auth.md#실행과-저장)을 따른다. 기존 KIS 환경 변수, 승인된 저장소 밖 SIWC 인증, 필요한 XML·PDF 도구를 준비한다. 키·토큰을 명령 인수나 진단 기록에 넣지 않는다.
2. [보고서 실행 안내](buy-candidates.md#준비와-실행)의 명령과 명시적 모델을 사용한다. 실제 명령·시작·종료 시각·종료 코드와 실행 전후 소스 지문을 접근이 제한된 저장소 밖 기록에 남긴다. 원문 인증 파일은 복사하지 않는다. 공유 기록에는 개인 인증 경로를 제외한다.
3. 종료 코드 0과 stdout의 JSON 하나를 확인한다. `dataSession`·`targetSession`과 `sourceUniverse.observations`·각 일봉의 요청·수신 시각, `evaluatedAt`을 구분한다. 후보가 있으면 `referenceClose`·`evidence`·`observation`·`risks`를 확인하고, 후보 없음이면 그 이유를 읽는다. 종료 코드 2의 분석 불충분이나 종료 코드 1의 실패를 후보 없음으로 해석하지 않는다.
4. [구독 한도 전환](buy-candidates.md#구독-한도-소진-시-유료-전환)에서 적용 단계를 확인한다. 추천·의미 검토의 공식 한도 소진에서만 별도 API 인증을 사용한다. `paid.reservedUsd`는 확보한 최대 비용이며 청구액이 아니다. 인증·네트워크·불명확한 사용량·일반 속도 제한으로 전환하지 않고 예산을 늘리거나 미완료 요청을 자동 반복하지 않는다.
5. 실패 시 [보고서 오류](buy-candidates.md#실패-확인)의 `error`·`stage`·`usage`·`observation`을 확인한다. `DATA_NOT_READY`는 필수 자료 준비 실패, `MARKET_ACTIVE`·`TARGET_OPEN`은 실행 시간 범위 이탈이다. 부분 출력을 매수 판단에 사용하지 않는다. `AUTH_COOLDOWN`은 남은 시간 뒤 새 실행에서 확인하고, 저장·잠금 오류는 [수동 복구](kis-auth.md#실패-뒤-복구)를 따른다. 통신 오류를 토큰 만료로 추정하지 않는다.
6. 후보가 있으면 표시한 다음 정규장용 검토라는 점과 체결가격 미보장을 확인한다. 토스증권에서 해당 종목의 소수점 거래 가능 여부와 예약 접수 조건을 직접 확인한 뒤 사용자가 단순 매수를 예약한다. 자동 예약·주문은 수행하지 않으며 개장 후 새 판단으로 재사용하지 않는다. 후보 없음이면 예약할 종목을 강제로 만들지 않는다.

## 인수 재개 조건

필요한 데이터가 준비된 한국 낮에 별도 승인한 통합 실행을 수행하고 요청·수신·결과 시각과 완료 세션·다음 세션을 기록해야 한다. 정상 후보 없음도 유효하되 전부 미확인인 분석 불충분과 구분한다. 고정 12시·15시 반복 실행이나 후보 강제 생성, 의도적인 구독 소진, 공급자 답변 대기, 실제 주문을 새 조건으로 추가하지 않는다.

유형 조사 충분성과 ADR 누락은 [#277](https://github.com/mochafreddo/stock-scout/issues/277)의 별도 품질 과제다. 공식 공지 완전성·유형·추천 의미 판단의 미검증 한계도 유지한다. 이번 작업에서 원격 이슈·체크박스·상태는 변경하지 않는다.
