# 2026-10-19 장전 세 시점 관측

[#249](https://github.com/mochafreddo/stock-scout/issues/249)의 실제 관측 27건을 완료했다. 모든 조회가 종료 코드 0으로 끝났지만 **직전 완료 정규장 데이터와 장전 지원 시간의 검증은 미완료**다. [부모 #243](https://github.com/mochafreddo/stock-scout/issues/243)과 #239·#245 및 후속 추천의 차단을 유지한다. 18:55의 준비 조회는 아래 27건에 포함하지 않는다.

각 시점의 순서는 volume NAS, amount NAS, volume NYS, amount NYS, volume AMS, amount AMS, daily NAS AAPL, daily NYS TSM, daily AMS SPY다. 기존 [기록 도구](kis-observe.md)를 사용해 순차 조회했고 호출 사이에 1초 간격을 뒀다. 이는 공급자의 검증된 호출 한도가 아니다. 지연은 응답의 requestedAt과 목표 시각의 차이다. receivedAt은 응답 처리 시각이며 기록 프로세스 종료 시각과 다르다. 시각은 운영체제 시계 기준이며 별도 시계 오차를 검증하지 않았다.

27건 모두 100행이며 validation=unverified, dataSession=null을 유지한다. 여섯 순위의 각 응답은 rank 1~100, 해당 tvol 또는 tamt 내림차순, continuation=F였다. 행 수 100을 최대 페이지 크기나 최종 N으로 확정하지 않는다. 후속 페이지는 요청하지 않았다.

## 요청 조건과 재확인 근거

## 공식 일정 확인 범위

[NYSE 연간 일정](https://www.nyse.com/trade/hours-calendars)과 [Nasdaq 연간 일정](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)을 기준으로 정규장 예정 개장을 09:30 EDT, 22:30 KST로 잡았다. NYSE 연간 일정 직접 GET은 성공했다. Nasdaq 연간 일정 직접 GET은 타임아웃이었으며 같은 공식 페이지를 웹 읽기 도구로 확인했다. 이 경로 차이를 직접 수집 성공으로 바꾸지 않는다.

관측 전에 NYSE Market Status와 Trader Updates 최신 100개씩, Nasdaq Equity RSS 46개와 현재 상태를 읽었다. 22:00·22:15 전에는 최신 공지·상태를 다시 읽었다. 조회 범위에서 주식 정규장 개장 변경은 찾지 못했다. 10월 19일 적용 NYSE American 연장거래 공지 110000960906은 옵션 대상이었고, 새 공지 110000961004는 채권 청산 상태 변경이었다. Nasdaq HINC의 09:30 quotation/약 09:40 거래 개시는 개별 ETF 안내로 구분했다.

이는 필요한 모든 과거·미래 적용 공지, 자식 공지 갱신, 정정과 시간 변경을 전수 검증한 결과가 아니다. 공식 일정 입력의 완전성·현재성과 #244의 남은 조건은 유지한다. 일정 CLI 완성 자체를 관측의 새 선행 조건으로 추가하지 않는다.
