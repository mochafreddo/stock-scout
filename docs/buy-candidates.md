# 매수 후보 보고서 제품 기록

이 문서는 제거된 KIS·내장 모델 제품의 목적과 한계를 보존한다. 현재 제품은 [토스 전환 기록](toss-transition.md)을 따른다. 당시 명령·인증·출력·오류 계약은 [제거 전 실행 안내](https://github.com/mochafreddo/stock-scout/blob/aa914669a4d692891e3683112449149cca6b2512/docs/buy-candidates.md)에 남아 있으며 현재 체크아웃의 실행 안내가 아니다.

## 당시 제품과 결정

공식 거래 일정과 후보군 검사를 통과한 종목을 ChatGPT 구독 모델로 검토하고, 직전에 끝난 미국 정규장까지의 KIS 일봉을 바탕으로 다음 정규장의 매수 검토 후보를 최대 5개 제시했다. 정상 후보 없음과 분석 불충분·실행 실패를 구분했으며 주문과 예약 등록은 사용자가 맡았다.

[후보군 기록](candidate-universe.md)의 최근 20개 완료 세션과 전체 600초·다음 개장 마감을 적용했다. 후보 선정과 별도 의미 검토는 합산 최대 4회·180초를 공유했고, 이미 검증한 일봉만 읽으며 추가 KIS 조회를 보내지 않았다. 근거는 [ADR 0015](adr/0015-subscription-buy-candidate-report.md)에 있다.

추천·의미 검토의 명시적 구독 한도 소진에만 같은 모델의 유료 API 전환을 허용했다. 일정·유형 단계와 일반 인증·통신 오류는 전환 대상이 아니었다. 비용을 보장할 수 없으면 추가 생성을 보내지 않는 결정은 [ADR 0016](adr/0016-bounded-paid-recommendation.md)에 있다.

## 인수 근거와 한계

2026년 11월 3일 한국 낮 통합 실행에서 완료 일봉을 사용한 정상 후보 없음 보고서를 확인했다. 후보가 있는 보고서의 실연동, 한국 낮 전체의 가용성, 추천 품질은 미검증이다. 실행 근거는 [첫 버전 인수 기록](first-version-acceptance.md#2026-11-03-한국-낮-통합-실행)과 [보고서 실행 이력](buy-candidate-history.md)에 있다.

코드는 가격·거래량을 원자료에서 복원하고 종목·날짜 연결을 검사했으며, 별도 모델이 선정 근거의 의미를 검토했다. 두 모델 모두 오판할 수 있고 독립 정답 표본으로 추천 정확도를 입증하지 않았다. 실패한 의미 검토를 자동 수정·재시도하지 않았다.

순위는 조회 당시의 탐색 자료이며 완료 세션 순위가 아니었다. 일봉의 정규장 범위는 승인된 KIS 필드 운영 가정이었고 수정주가를 반영하지 않았다. 공식 일정 공지 수집 완전성과 모델의 의미적 신뢰도는 미검증으로 남았다. 계좌·보유 내역·매도·유지·금액·비중·주문 연동은 다루지 않았다.

모의 CLI·HTTP 회귀 검사는 실제 구독·KIS 호환성, 추천 유용성이나 토스증권 거래 가능 여부를 입증하지 않는다. 관측 필드와 당시 오류 분석은 [공통 관측 설계](rca-observability-design.md)와 [보고서 실행 이력](buy-candidate-history.md)에 보존한다.
