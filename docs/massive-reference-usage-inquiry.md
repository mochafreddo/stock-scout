# Massive 참조 메타데이터 이용 범위 문의 초안

> 이 문서는 제거된 KIS·내장 모델 제품의 당시 기록이다. 현재 제품은 [토스 전환 기록](toss-transition.md)을 따른다. 아래 조사와 미확인은 당시 이력이며 현재 제품의 공급자 채택 조건이 아니다.

2026-10-19 [제3자 공급자 조사](third-party-security-type-sources.md)의 후속 확인을 위해 작성한 초안이며 전송하지 않았다. 공개 자료만으로 해소하지 못한 적용 관계와 미전송 사실을 남긴다.

2026-10-20 당시 차단 범위는 [재검토 보고서](third-party-security-type-sources.md#2026-10-20-자동-이용보관-차단-범위-재검토)를 따른다. 당시 초안을 공급자에게 보내는 일은 다음 단계의 필수 조건이 아니었다. 자동 이용의 미해결 적용 관계, 보관·삭제 방법, 결과 공개 범위를 분리하고 보관 기간 설명 부족이나 결과 공개 미확정만으로 비공개 검증을 차단하지 않는다. 문의 전송과 답변 대기를 다음 필수 단계로 두지 않는다.

## 확인한 근거와 남은 질문

[Individuals Terms §1–§2](https://massive.com/legal/individuals-terms-of-service)는 개인·비상업·비사업 목적의 사용권과 Market Data Terms의 추가 적용을 명시한다. [개인 앱 안내](https://massive.com/knowledge-base/article/which-plan-do-i-need-to-show-massive-data-in-my-app)는 본인만 사용하는 개인 앱·연구·스크립트·거래를 개인 요금제 범위에 포함한다. 당시 초안에는 개인 스크립트에 관한 안내가 있다는 점을 반영했다.

그러나 [Market Data Terms](https://massive.com/legal/market-data-terms-of-service) §2의 기본 표시용 제한, §5(c)의 데이터에 기반하거나 이를 참조한 연구 등을 포함하는 Derived Works의 제3자 공유 제한, §5(d)의 비표시 이용·투자 전략 등 파생물 생성 제한과 이 안내의 관계는 해당 CLI 용도에 대해 확정하지 못했다. §9는 약관 충돌 시 Market Data Terms의 우선을 규정한다. 개인 스크립트 안내만으로 참조 필드의 자동 분류나 원자료 없는 결과 공개까지 허용됐다고 판단하지 않는다.

비공개 보관도 별도 확인 대상이다. Market Data Terms §8은 계약·계정의 종료뿐 아니라 제한·정지 시에도 사용 중단과 보유 Market Data 삭제를 요구한다. 필요한 참조 응답의 보관 기간과 백업·분류 결과에 적용되는 삭제 범위도 미확인으로 남겼다. 공개 문서의 제한을 확인한 것과 이 구체적 사용이 금지됐다고 판단하는 것은 구분한다.

## 미해결 쟁점과 미전송 상태

문의 메일은 전송하지 않았다. 당시 초안은 다음 적용 관계를 구분해 확인하려는 목적이었다.

- 참조 필드의 자동 조회·KIS 증권 연결·유형 분류·후보군 포함 판단에 필요한 권한과 개인 스크립트 안내의 관계.
- 검증용 응답·캐시·백업·분류 결과의 비공개 보관 및 종료·제한·정지 시 삭제 범위.
- 원자료 없는 검증 절차·일반 결론과 종목별 판정 결과의 공개 범위.
- 해당 이용에 필요한 요금제·추가 권한·제3자 약관·구독자 자격.

## 종료와 후속 경계

문의 초안 준비로 이번 공개 자료 확인을 종료하며 공급자 답변을 기다리는 일을 새 구현 선행 조건으로 추가하지 않는다. 문의 전송 여부는 별도 결정이다. 공개 자료만으로 해소되지 않은 이용 범위는 판단 보류로 유지하고, 재개에는 위 구체적 이용에 적용되는 공개 조건이나 별도로 확보한 명시적 허용 근거가 필요하다.

이번 문서는 공급자 채택, 가입·약관 동의·키 발급·결제·인증 API 호출, 원응답 보관이나 공개를 실행한 기록이 아니다. 이용 권한을 확인하더라도 실제 유형·증권 연결·현재성 검증은 다음 단계이며 #250과 후속 작업의 기존 미검증 조건과 차단을 유지한다.
