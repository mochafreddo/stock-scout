# Massive 참조 메타데이터 이용 범위 문의 초안

2026-10-19 [이용 범위 확인 설계](security-type-probe-design.md#massive-이용-범위-확인의-후속-설계-인터뷰)에 따른 초안이다. [제3자 공급자 조사](third-party-security-type-sources.md)의 후속 확인을 위한 문서이며 전송하지 않았다. 공개 자료만으로 해소하지 못한 적용 관계를 질문으로 남긴다.

## 확인한 근거와 남은 질문

[Individuals Terms §1–§2](https://massive.com/legal/individuals-terms-of-service)는 개인·비상업·비사업 목적의 사용권과 Market Data Terms의 추가 적용을 명시한다. [개인 앱 안내](https://massive.com/knowledge-base/article/which-plan-do-i-need-to-show-massive-data-in-my-app)는 본인만 사용하는 개인 앱·연구·스크립트·거래를 개인 요금제 범위에 포함한다. 따라서 개인 스크립트에 관한 안내가 없다는 전제로 문의하지 않는다.

그러나 [Market Data Terms](https://massive.com/legal/market-data-terms-of-service) §2의 기본 표시용 제한, §5(c)의 데이터에 기반하거나 이를 참조한 연구 등을 포함하는 Derived Works의 제3자 공유 제한, §5(d)의 비표시 이용·투자 전략 등 파생물 생성 제한과 이 안내의 관계는 해당 CLI 용도에 대해 확정하지 못했다. §9는 약관 충돌 시 Market Data Terms의 우선을 규정한다. 개인 스크립트 안내만으로 참조 필드의 자동 분류나 원자료 없는 결과 공개까지 허용됐다고 판단하지 않는다.

비공개 보관도 별도 확인 대상이다. Market Data Terms §8은 계약·계정의 종료뿐 아니라 제한·정지 시에도 사용 중단과 보유 Market Data 삭제를 요구한다. 필요한 참조 응답의 보관 기간과 백업·분류 결과에 적용되는 삭제 범위는 아래 질문에 포함한다. 공개 문서의 제한을 확인한 것과 이 구체적 사용이 금지됐다고 판단하는 것은 구분한다.

## 문의 초안

수신 후보는 `support@massive.com`이다. [공식 약관 안내](https://massive.com/legal/terms)가 약관 질문의 연락처로 명시한다. 개인 앱 안내는 용도와 요금제 질문에 contact 페이지 또는 sales 연락처도 제시하지만 이번에는 전송하지 않는다.

**제목: 개인 CLI의 주식 참조 메타데이터 자동 이용·비공개 보관·검증 결론 공유 범위 확인**

> 안녕하세요. 개인이 터미널에서 실행하는 비상업·비사업 목적의 CLI에 Massive 주식 참조 메타데이터를 이용할 수 있는지 확인하고자 합니다. 도구의 실행 결과와 Massive 데이터는 본인만 열람하는 용도를 검토하고 있습니다. 다른 사람에게 데이터나 도구 실행 서비스를 제공하려는 용도는 아닙니다.
>
> Massive에서는 종목 유형과 개별 증권 식별에 필요한 참조 자료만 자동 조회하려고 합니다. 검토 대상은 Ticker Types, All Tickers, Ticker Overview이며, 필요한 필드는 유형 코드와 설명, `ticker`, `primary_exchange`, `composite_figi`, `share_class_figi` 등입니다. 이를 한국투자증권(KIS)의 거래소·원본 종목 코드와 연결하고, 보통주 또는 보통주 성격의 ADR인지에 따라 후보군 포함 여부를 코드로 판단하려고 합니다. 우선주·워런트·ETF·ETN과 유형을 확인할 수 없는 종목은 제외하는 용도입니다.
>
> 시세·거래량·거래대금·순위는 KIS에서 수집하며 Massive에서 받으려는 자료에 포함하지 않습니다. Massive 참조 자료에 따른 증권 연결과 유형 판정은 이후 개인 매수 검토에 사용할 후보군을 정하는 데 영향을 줍니다. 자동 조회와 판정을 단순 화면 표시로 간주할 수 있다고 전제하지 않습니다.
>
> Individuals Terms §1–§2, Market Data Terms §2·§5(c)·§5(d)·§8·§9와 개인 앱 안내를 읽었습니다. 안내에는 개인 연구·스크립트·거래가 포함되어 있으나, 아래 각 이용에 적용되는 권한과 제한을 구분하여 확인하고 싶습니다.
>
> 1. 위 참조 엔드포인트와 필드에도 Market Data Terms의 기본 표시용 제한과 비표시 이용·투자 전략 관련 제한이 적용되는지 확인을 요청합니다. 개인 앱·스크립트 안내와 해당 조항이 이 용도에 어떻게 함께 적용되며, 문서 간 차이가 있을 때 어떤 조건이 우선하는지 알고 싶습니다. 해당 범위가 기본 개인 라이선스에 포함된다면 근거 조항을, 별도 권한이 필요하다면 대상 엔드포인트·필드·이용별로 필요한 허가나 계약을 알려 주세요.
>
> 2. 참조 자료의 자동 조회, KIS의 개별 증권과 연결, 코드에 의한 유형 분류, 후보군 포함·제외 판단이 각각 개인 요금제에서 허용되는지 확인을 요청합니다. 이 중 non-display use 또는 투자 전략·파생물 생성으로 취급하는 단계가 있다면 어느 단계인지, 필요한 추가 권한은 무엇인지 알려 주세요.
>
> 3. 분류의 정확성을 검증하고 오류를 재현하기 위해 필요한 참조 응답과 조회 시각을 저장소 밖의 본인만 접근하는 비공개 위치에 보관할 수 있는지 확인을 요청합니다. 허용되는 보관 기간·분량·갱신 조건, 캐시와 백업의 취급, 구독 해지·계정 제한·정지 시 삭제 의무를 알려 주세요. 원응답 외에 증권 연결·유형·포함 여부를 기록한 결과에도 같은 보관·삭제 의무가 적용되는지 알고 싶습니다.
>
> 4. 원응답·원자료를 공개하지 않고 공유 저장소 문서에 검증 방법·결론·한계를 기록하는 범위를 확인하고 싶습니다. 데이터값을 담지 않은 일반적인 검증 절차와 코드 설명, 실제 데이터에서 얻은 종목별 유형·포함 여부 및 검증 성공·실패 결론을 구분했을 때 각각 공개할 수 있나요? 후자가 §5(c)의 Derived Works에 포함되거나 별도 공개 허가가 필요하다면, 공개 가능한 결론의 범위와 필요한 허가·표시 조건을 알려 주세요. 원자료를 제외했다는 이유만으로 공개 가능하다고 전제하지 않습니다.
>
> 5. 위 이용을 허용하는 직접 가입 가능한 요금제와 추가 비용이 있는지, Stocks Basic으로 가능한지 확인을 요청합니다. 참조 자료의 출처에 따라 추가 제3자 약관·권한이나 별도 동의가 필요한지도 알려 주세요. 전문·비전문 구독자 자격을 이 설명만으로 확정하려는 것은 아니며, 가입 전 확인해야 할 자격 기준과 절차가 있다면 함께 안내를 요청합니다.
>
> 각 항목에 대해 기본 계약으로 허용되는 범위, 명시적 제한, 별도 승인이 필요한 범위를 구분하고 적용 문서나 조항을 알려 주시면 검토에 도움이 됩니다. 감사합니다.

## 종료와 후속 경계

문의 초안 준비로 이번 공개 자료 확인을 종료하며 공급자 답변을 기다리는 일을 새 구현 선행 조건으로 추가하지 않는다. 문의 전송 여부는 별도 결정이다. 공개 자료만으로 해소되지 않은 이용 범위는 판단 보류로 유지하고, 재개에는 위 구체적 이용에 적용되는 공개 조건이나 별도로 확보한 명시적 허용 근거가 필요하다.

이번 문서는 공급자 채택, 가입·약관 동의·키 발급·결제·인증 API 호출, 원응답 보관이나 공개를 실행한 기록이 아니다. 이용 권한을 확인하더라도 실제 유형·증권 연결·현재성 검증은 다음 단계이며 #250과 후속 작업의 기존 미검증 조건과 차단을 유지한다.
