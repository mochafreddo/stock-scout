# KIS 명시적 만료의 조건부 캐시 무효화

[#248](https://github.com/mochafreddo/stock-scout/issues/248)의 설계 인터뷰에서 2026-10-18 합의한 결정이다. 조회 중 명시적 토큰 만료를 확인하면 공통 발급 잠금 안에서 최신 캐시를 확인하고, 거절된 토큰과 현재 자격 증명에 연결된 캐시 토큰이 일치할 때만 무효화한다. 다른 실행이 이미 저장한 현재 자격 증명의 유효한 토큰은 보존하고, 추가 발급 없이 한 번 재조회한다. 무조건 캐시를 지우는 방식보다 다른 실행의 갱신을 보존하고 중복 발급을 줄이는 방식을 선택한다.

만료가 확인된 토큰은 발급 시도 간격 300초에 막혀 이번 실행이 실패해도 이후 실행에서 재사용하지 않는다. 토큰 무효화는 발급 시도 기록을 초기화하지 않으며, 잠금 충돌·안전한 저장 실패·발급 제한에서는 기존 정책에 따라 성공 결과 없이 실패한다.

한 번 복구한 뒤 재조회에서도 명시적 만료가 발생하면 두 번째로 거절된 토큰도 같은 일치 조건으로 무효화하고 추가 발급 없이 실패한다. 다른 실행이 저장한 토큰은 이 경우에도 보존한다. 다른 인증·통신 오류만으로 토큰을 무효화하지 않는다.

복구 발급에서 방금 만료로 거절된 것과 같은 토큰을 반환하면, 만료 일시가 미래여도 저장하거나 재조회에 사용하지 않고 실패한다. 이미 확인한 서버의 만료 판단을 만료 일시만으로 뒤집지 않으며 발급 시도 기록은 보존한다.

HTTP 200과 `rt_cd: "0"` 같은 성공 표시가 구조화된 `EGW00123` 오류 코드와 함께 있으면 모순된 응답으로 실패한다. 정상 형태의 데이터가 있어도 성공으로 인정하지 않으며, 자동 복구도 수행하지 않는다. 정상 데이터의 존재와 성공·오류 표시의 충돌은 구분한다.

이 기록은 캐시 무효화와 모순된 응답 처리에 관한 설계 합의다. 설계 합의 당시에는 조회 중 복구의 구현·모의 검사·음성 대조·실연동 검증을 수행하지 않았다. 이후 구현과 검증 범위는 [KIS 인증과 복구](../kis-auth.md)에 구분해 기록한다.
