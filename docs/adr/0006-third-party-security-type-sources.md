# 종목 유형과 증권 연결에 제3자 공급자를 검토한다

[#250](https://github.com/mochafreddo/stock-scout/issues/250)의 2026-10-19 후속 설계 인터뷰에서 종목 유형과 개별 상장 증권의 연결 자료에 한해 자동 이용을 허용하는 제3자 데이터 공급자를 검토 대상에 포함하기로 합의했다. 무료·공개 공식 자료를 조사했지만 채택 경로를 확정하지 못하여, 공식 출처만 허용하는 제약을 유지하는 대신 계약에 따라 자동 이용할 수 있는 공급자까지 비교 범위를 넓힌다. 이는 해당 자료의 공급자 범위에 관한 ADR 0005의 결정을 확장하며 시세·거래량·거래대금·순위는 KIS로 유지한다.

무료 요금제로 요구사항을 충족하는지 먼저 조사한다. 유료 공급자는 가격과 필요한 요금제까지 비교하고 구체적인 후보를 확인한 뒤 예산을 정한다. 무료라는 이유로 검증 기준을 낮추지 않는다. 개인이 직접 가입하고 API 키를 발급받아 이용할 수 있는 서비스를 검토하며 영업 문의·별도 협상·기업 계약이 필수인 서비스는 이번 조사에서 제외한다.

공급자가 문서로 정의한 증권 유형을 판별 근거로 인정하며 모든 종목에 발행사 원문 대조를 요구하지 않는다. 분류의 문서상 의미와 실제 표본의 대응은 확인해야 한다. ADR 표시만으로 보통주 성격을 확정하지 않으며 공급자 분류가 보장하지 않는 기초 권리는 추정하지 않는다. 기존 BBD/BBDO·워런트·SPY/VXX 반례와 확인된 모순도 검증한다.

공개 문서로 후보를 추린 뒤 유망한 공급자 최대 3개를 이용 조건·유형·증권 연결·최신성·비용 기준으로 상세 비교한다. 충족하는 후보가 없으면 부족한 조건과 보류 사유를 기록하고 이번 조사를 종료한다. 실제 응답이 필요한 항목은 미검증으로 남긴다.

이번 합의는 공급자 채택이나 가입·약관 동의·결제·자격 증명 생성·실연동 실행의 승인이 아니다. 실제 가입과 키 발급은 공급자를 선택한 뒤 별도로 진행한다. 개별 증권 연결, ADR의 기초 권리, 자료의 현재 적용 가능성과 확인된 반대 근거의 해결은 계속 검증해야 하며, 제3자 공급자 허용 자체를 검증 완료로 취급하지 않는다. 기존 미검증 조건과 후속 구현 차단은 유지한다.
