# 토스 조회 도구로 전환하고 기존 KIS·내장 모델 경로를 제거한다

[#278의 통합 전환 명세](https://github.com/mochafreddo/stock-scout/issues/278)와 [#283의 계약](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791)에 따라 제품을 TypeScript 로컬 JSON 조회 CLI로 전환한다. 외부 에이전트가 조회 순서와 의미 판단·추천을 맡으며, 내부 코드는 조회·검증·페이지·한도·오류를 담당한다. 내장 모델과 전용 인증·유료 전환·비용 제한을 함께 제거하여 두 제품의 의존성을 유지하지 않는다.

[#299](https://github.com/mochafreddo/stock-scout/issues/299)의 착수 기준은 `aa914669a4d692891e3683112449149cca6b2512`다. 합성 검사·실제 시장 및 계좌 조회·Codex와 dots 연결의 선행 인수와 사용자 예외 결정을 [전환 기록](../toss-transition.md)에 연결한다. 공급자 조회 전용 권한과 세부 처리·보관 조건은 완전히 확인된 것으로 바꾸지 않으며, dots 결과는 사용자 보고로 구분한다.

KIS 인증·조회·프로브·관측, 후보군과 완료 일봉 공통 관문, 추천 CLI와 유형 웹 검색, 내장 유형·일정·추천·의미 검토 모델을 제거한다. 옛 명령·JSON·관측 파일의 호환 계층과 KIS 자동 복귀는 제공하지 않는다. 기존 인증 저장소와 환경 파일을 삭제하거나 마이그레이션하지 않는다. 새 MCP·HTTP 서버·예약 실행·주문 변경 기능은 추가하지 않는다.

ADR 0001~0003과 0005~0018은 제거된 제품 경로의 당시 결정으로 남는다. ADR 0004의 커밋 대상 스냅샷 검사 정책은 유지한다. 현재 토스 계약은 명령별 조회이며 기존 보고서의 후보 수·20개 완료 일봉·공통 세션 관문을 승계하지 않는다. 과거 인수·연구 증거는 당시 이력이며 새 제품의 실행 검증으로 취급하지 않는다.
