# 커밋 대상 스냅샷을 검사한다

2026-10-18 개발 환경 설계 인터뷰에서 stock-scout의 push 직전 검사에 커밋 단계 검사를 추가하기로 합의했다. 작업 디렉터리의 미커밋 수정이 오류를 가리지 않도록 staged 스냅샷에서 문서의 공백과 로컬 링크를 검사하고 코드의 형식·린트·타입 검사도 실행한다. 검사에 실패하거나 검사를 실행할 수 없으면 자동으로 수정하지 않고 커밋을 차단한다. 중간 커밋의 편의보다 커밋 대상이 최소 검사 기준을 충족하는 것을 우선한다. 전체 테스트는 최종 검증과 pre-push에서 계속 실행하며 다른 저장소의 훅과 Actions 정책은 바꾸지 않는다. 이는 설계 결정이며 구현·설치 완료를 뜻하지 않는다. 후속 세부 설계는 [커밋 단계 검사 설계](../development-guardrails-design.md)에 기록한다.
