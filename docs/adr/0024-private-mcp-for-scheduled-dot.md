# 예약 Dot은 비공개 MCP로 시장 자료를 조회한다

예약 Dot은 분석 중 후속 조회를 선택할 수 있어야 한다. 로컬 실행기를 직접 호출하는 예약 환경에서는 macOS 부팅 세션 정보 읽기가 차단되어 준비 점검을 통과하지 못했다. Mac에서 기존 승인 CLI가 토스 인증·조회·호출 제한을 맡고, 예약 Dot은 OpenAI의 비공개 MCP 터널을 통해 조회를 요청하고 결과를 분석한다.

2026-11-24 KST 예약 검증에서 Dot은 합성 순위 응답을 바탕으로 일봉을 후속 조회했다. 별도 실연동에서는 실제 시장 시세 한 건을 받아 공급자 가격 시각과 CLI 조회 시각을 구분했다. 이 결과는 연결 방식의 검증이며 반복 운영, 절전 후 동작과 장애 복구는 검증하지 않았다.

이 결정은 [ADR 0019](0019-toss-query-tools-transition.md)의 로컬 JSON CLI와 외부 분석 책임을 유지하면서 예약 Dot에 비공개 조회 연결을 추가한다. 첫 시장 보고서는 `rankings`, `stock`, 일봉 `candles`, `prices`, `sessions`를 사용한다. 계좌·보유·주문 자료의 접근과 전달은 별도로 결정한다.

사용자 `LaunchAgent`는 보고서 시간대에만 Mac의 MCP 서버와 터널을 실행한다. 기존 21:00 KST Dot 예약의 시범 운영에서 새 조회는 20:55부터 21:20 직전까지만 시작한다. 실제 조회 전에 기존 승인 실행기의 로컬 조회 준비 점검을 수행한다. 마감에는 대기 중인 요청까지 새 조회 시작을 차단하고, 이미 시작한 조회는 기존 실행 한도 안에서 마친 뒤 응답을 전달하고 터널을 닫는다. Mac이 마감 이후에 깨어나면 해당 회차를 건너뛴다.

회차 보고는 준비 점검으로 인한 조회 미시작, 실제 조회 오류, 부분 결과와 결과 확인 불가를 구분한다. 일부 조회만 성공하면 확보 범위와 누락을 밝힌다. 이전 회차의 결과를 사용하지 않는다. 로컬 운영 로그에는 회차·시각·상태·오류 코드만 남긴다.

시범 운영의 회차당 시장 조회 상한은 16건이며, 한 번에 한 건만 시작한다. 실제로 시작한 시장 조회만 세므로 실패·부분 결과·후속 페이지도 각각 한 건으로 계산한다. 준비 점검은 제외한다. 비정상 종료 이후 같은 회차를 자동 재개하지 않으며 재시작으로 조회 예산을 초기화하지 않는다.

저장소에는 선택형 MCP 어댑터와 `LaunchAgent` 설정 예시를 둔다. 실제 실행기 경로와 키 설정은 Mac에서 관리한다. 어댑터는 합의한 조회의 인수만 받아 기존 CLI에 전달하고, CLI의 결과 상태·종료 코드·페이지 경계를 보존한다. 기존 CLI의 직접 호출 계약을 유지한다.

합성 검증은 공개 MCP 도구와 기존 CLI 인수·JSON·종료 코드 경계에서 준비 점검 차단, 시간 마감, 조회 예산, 재시작과 부분 결과를 확인한다. 운영 인수에서는 Mac `LaunchAgent`와 21시 예약 Dot을 실제로 사용해, 한 회차에서 시장 자료를 조회하고 그 결과에 따른 후속 조회를 거쳐 보고서를 완성하는지 확인한다.

## 예약 종료 상한

2026-11-25에 이미 시작한 조회의 응답 전달 기회와 종료 상한을 함께 두기로 합의했다. 종료 시작 즉시 새 연결과 조회 시작을 차단하고, 진행 중인 조회와 응답 전달이 끝나면 터널 종료를 시작한다. 기존 실행기 한도 70초에 응답 유예를 더해 종료 시작 75초까지 기다린 뒤, 남은 연결을 닫고 관리 중인 자식과 터널에 종료 신호를 보낸다. 필요하면 80초에 강제 종료하며 이후 해당 프로세스나 파이프를 다시 기다리지 않는다.

응답 전달을 확인하지 못하면 결과 확인 불가로 처리하고 회차 점유는 보존한다. 이 상한은 실행기가 종료 절차를 시작할 수 있는 경우에 적용한다. 실행기의 비정상 종료 후 실제 터널 정리는 별도 검증 범위다. [검토 후속 결정](../review-remediation.md#2026-11-25-전체-코드베이스-검토-후속-결정)
