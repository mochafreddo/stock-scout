# 공식 공지의 일정 영향은 LLM이 판단하고 코드는 일정을 계산한다

2026-10-28 [#244](https://github.com/mochafreddo/stock-scout/issues/244)의 설계 인터뷰에서 정해진 단문 형식과 일치해야 통과하는 공지 해석을 LLM의 의미 판단으로 바꾸기로 합의했다. 실제 여러 문단 공지를 형식마다 추가하는 유지 비용을 줄이는 대신, 모델이 일정 영향을 잘못 배제할 위험과 구독 인증 의존성을 받아들인다. 코드의 구조·근거 연결 검사로 의미적 정확성을 증명할 수 없으므로 독립 정답이 있는 실제 공지 표본으로 별도 평가한다.

공식 메타데이터로 명시적인 비대상 시장을 제외한 뒤, 수집한 대상 공지 본문 전체와 부모·자식·공지 사이의 관계를 한 번의 모델 요청에서 판단한다. 모델에는 KIS·검색·추가 링크 조회 도구를 제공하지 않는다. 기존 KIS 상품 정보는 개별 증권의 속성이며 전체 거래소 일정의 근거가 아니고, 해외결제일자조회도 정규장 개폐장 시간을 제공하는 자료로 확인하지 못했다. KIS 일봉 준비 검사는 #245·#251의 후속 흐름에 둔다.

모델은 일정 영향·적용일·시간·정정 관계와 본문 근거를 제시한다. 코드는 입력 소속·본문 근거 연결·누락·중복·날짜·시간·정정 참조를 검사하고 휴장·개장 지연·조기 폐장과 해결된 정정·철회를 일정에 반영한다. 불확실·상충·미해결 관계는 전체 실패다. 일정을 모델이 직접 계산하거나 모델의 자신감 점수만으로 성공시키지 않는다. 한계와 공지별 판단·짧은 이유·근거는 결과에 남긴다.

실제 전체 실행에서 본문 ID와 인용의 잘못된 조합·공백 변경을 확인한 뒤, 모델의 문자열 복사를 코드의 구간 ID·원문 복원으로 바꾼다. 전체 본문을 빠짐없이 구간으로 전달하고 모델은 근거 구간을 선택한다. 정확한 원문 연결은 코드가 보장하지만 선택한 구간이 결론을 뒷받침하는지는 여전히 의미 검증 대상이다.

기존 Stock Scout 전용 SIWC 인증과 명시적으로 지정한 모델을 사용한다. 첫 실제 검증 후보는 `gpt-6-luna`이며 모델 대체·유료 API 전환은 없다. 지침·스키마·공지 데이터가 포함된 입력 상한은 256KiB, 모델 요청은 한 번, 전체 실행은 300초, 공식 자료 수집은 120초, 개별 수집 요청은 15초, 모델 판단은 전체 남은 시간 안에서 최대 180초다. 초과·중단·미완료는 실패이며 자동 재시도·분할·요약·캐시는 추가하지 않는다. 이는 수용한 운영 상한이지 모델의 문맥 수용·처리 시간·정확성 보장이 아니다.

이 결정은 ADR 0012의 코드 전용 공지 해석과 #244의 LLM 없는 독립 실행 계약을 해당 범위에서 대체한다. 연간 공식 일정, 제한된 현재 공지 수집, 공지 완전성 미검증, NAS·NYS·AMS 공통 세션, 인접 연도 검사, 장중 제외와 출력 직전 재판정은 유지한다. `--at`의 현재 자료 해석과 독립 CLI의 확인된 분석 대상 아님에 대한 정상 종료도 유지한다. 실제 전체 CLI 정상 결과와 작은 실제 표본의 판단·근거 평가를 함께 확인하며, 회귀 검사와 음성 대조는 실제 모델 정확도와 구분한다. 세부 계약은 [설계 문서](../calendar-notice-assessment-design.md)에 기록한다.

검토 기준은 `4d4be69cca02776d441d1eadfba8df76861bd360`과 확보한 #244 원문 및 이번 설계 합의다. 공개 검증 경계는 CLI 인수·stdout·stderr·종료 코드와 외부 HTTP·모델 응답이다. 후속 `$implement` 요청은 구현·검증·로컬 커밋을 승인했으며 푸시·원격 이슈 갱신·종료는 포함하지 않는다.
