# Stock Scout를 새 이력과 최소 문서로 시작한다

2026-10-17 [#238](https://github.com/mochafreddo/stock-scout/issues/238) 설계 인터뷰에서 새 초기 커밋은 README.md, .gitignore, 새 요구사항을 반영한 AGENTS.md, 이를 참조하는 CLAUDE.md, 새 제품의 GLOSSARY.md와 이 결정 기록으로 시작하기로 했다. README는 [#237](https://github.com/mochafreddo/stock-scout/issues/237)을 명세의 기준으로 연결한다. 앱 코드와 패키지 설정은 후속 구현 티켓에서 추가하며, 기존 용어집과 ADR은 그대로 승계하지 않는다. 기존 MIT LICENSE는 내용 변경 없이 새 초기 커밋에 포함한다.

상위 명세는 기존 구현과 새 제품을 구분하기 위해 이름 변경과 기존 Git 이력·브랜치·태그 교체, 복구용 백업 미생성을 정했다. 기존 이력 보존을 요구하는 현재 저장소 지침과 충돌하므로, 실제 전환 전에 새 요구사항에 맞는 지침으로 교체한다. 이 문서는 설계 결정 기록이다. 실행 결과와 새 초기 커밋 SHA는 #238의 완료 기록에서 확인한다.

전환 전에 이름 충돌, 권한과 보존 대상을 확인한다. 전환 중 실패하면 후속 삭제를 멈추고 완료한 단계와 현재 상태를 기록한 뒤 실패한 단계부터 이어간다. 예를 들어 원격 이름 변경 후 이력 교체가 실패해도 자동으로 이름을 되돌리지 않는다. 백업 없이 진행하는 전환에서 추가 변경으로 상태를 더 복잡하게 만들지 않기 위한 결정이다.

기존 코드·문서·실행 산출물의 정리에는 미커밋 연구 문서 docs/issue-233-shares-research.md와 lobster 작업 트리의 기존 작업을 포함한다. 삭제 직전에 상태를 다시 확인하며, 인터뷰에서 확인하지 못한 새 변경은 해당 변경의 처리를 멈추고 별도로 판단한다. 기존 로컬 환경 변수 파일은 삭제 범위에서 제외하며 값의 노출이나 커밋 없이 보존 여부를 검증한다.

기존 GitHub 릴리스와 첨부 자산은 이전 버전 배포물을 새 출발 상태에 남기지 않기 위해 삭제한다. 인터뷰 시 GitHub API에서 릴리스 76개와 열린 PR 0개를 확인했으며, 실제 삭제 대상은 실행 직전에 다시 조회한다. 기존 이슈와 PR 기록은 유지한다. GitHub 내부 PR 참조 등 서버 내부 객체의 완전 삭제는 보장하지 않는다.

lobster 작업 트리의 연결을 정리한 뒤 로컬 .git을 재생성하여 이전 객체와 reflog를 제거한다. 브랜치와 태그만 교체하면 로컬 내부에 이전 이력이 남기 때문이다. 현재 설치된 비밀정보 유출 검사 pre-push 훅과 필요한 원격·인증 연결 설정은 확인 후 유지한다. 기존 인증정보 자체는 복사하거나 출력하지 않는다. 인터뷰에서 두 작업 트리가 공용 .git을 공유하고, stash 참조는 없으며, reflog 항목은 152개임을 확인했다. 이 수치는 실행 직전의 상태를 대신하지 않는다.

GitHub Actions의 과거 실행 기록, 산출물과 캐시도 삭제한다. 인터뷰 시 실행 기록 2,860개, 산출물 194개, 캐시 0개를 확인했다. Actions는 비활성화 상태를 유지한다. 실행 직전에 대상을 다시 조회하고, 정리 후 API로 결과를 확인한다. 이 삭제 역시 GitHub 서버 내부 객체의 완전 삭제를 보장하지 않는다.
