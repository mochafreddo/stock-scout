# 공식 일정과 제한된 변경 공지 수집을 운영 가정으로 사용한다

2026-10-28 [ADR 0013](0013-llm-calendar-notice-assessment.md)이 코드 전용 공지 해석과 LLM 없는 독립 실행 계약을 해당 범위에서 대체한다. 이 문서의 제한된 현재 공지 수집과 완전성 미검증 운영 가정은 유지한다.

2026-10-26 [#244](https://github.com/mochafreddo/stock-scout/issues/244)의 설계 인터뷰에서 공식 변경 공지의 완전성 입증을 첫 버전의 선행 조건에서 제외하기로 합의했다. 기존 조사로 공식 조회 경로를 확인했지만 공지 전체의 수집 범위·최신성·정정 반영은 입증하지 못했다. 이를 입증할 때까지 독립 일정 도구의 구현을 막는 대신, 공식 연간 일정과 실행마다 수집하는 제한된 공지를 사용하고 누락 위험을 명시하는 개인용 첫 버전을 선택한다. 이 결정은 ADR 0003의 공지 완전성 입증 관문을 대체하며, 과거 조사 결과를 검증 성공으로 바꾸지 않는다.

NYSE Market Status와 Trader Updates는 각각 게시일 내림차순 첫 페이지에서 부모 공지 최대 100건과 응답에 포함된 자식 공지 전체를 확인한다. Nasdaq은 현재 Equity RSS의 항목과 연결 본문을 확인한다. 후속 페이지·과거 아카이브·본문의 연쇄 링크는 자동으로 따라가지 않는다. 100건은 사용자가 합의한 수집 상한이며 공급자의 보존 범위나 완전성 보장이 아니다. 목록 밖의 유효한 공지, 오래된 부모 공지의 새 수정·철회, 미래 적용 공지를 놓칠 위험을 허용한다.

수집한 공지는 테스트로 확인한 형식만 코드로 해석한다. 일정에 영향을 줄 가능성을 배제하지 못한 공지의 대상 시장·적용일·개폐장 시간·정정 관계를 확정하지 못하면 실패한다. 제목만으로 무시하거나 LLM으로 추정하지 않는다. 지원할 공지 형식과 거래소 적용 근거의 확인은 구현 전 남은 작업이며, 이번 합의나 HTTP 성공이 자동 해석 가능성을 입증하지 않는다. 조회·해석 실패, 필요한 연간 일정·인접 연도 자료 누락, NAS·NYS·AMS의 기준·대상 세션 또는 개폐장 시각 불일치는 계속 전체 실패로 처리한다. 오래된 자료나 추정 일정으로 대체하지 않는다.

정한 수집·검사를 통과하면 독립 도구는 JSON 하나와 종료 코드 0을 제공한다. JSON에는 판정 시각과 자료 조회 시각을 구분하고 출처·채널·조회 조건·항목 수·목록에 표시된 날짜 범위·공지 완전성 미검증을 구조화된 필드로 표시한다. 관측한 날짜의 최솟값·최댓값을 연속적인 공지 보존 범위로 표현하지 않는다. 성공은 이 운영 가정 아래의 일정 계산이며 검증된 전체 공지나 실제 시장 운영의 보장이 아니다. 후속 후보군 CLI도 이 한계를 전달받으며 완전성을 다시 필수 관문으로 추가하지 않는다.

ADR 0009의 직전 폐장부터 다음 개장 직전까지의 일정상 분석 범위와 장중 제외, 출력 직전 재판정은 유지한다. 독립 일정 도구는 확인된 분석 대상 아님도 정상 JSON·종료 코드 0으로 출력한다. 최종 후보군 CLI의 장중·출력 직전 개장 거부는 별도 계약으로 유지한다. 검증용 `--at`은 `Z` 또는 UTC 오프셋이 있는 시각을 고정하고 현재 확보한 자료로 계산한다. 당시 알려져 있던 공지 상태의 복원은 보장하지 않으며 필요한 날짜의 자료가 없으면 실패한다. 최종 후보군 CLI의 과거 시각 지정 기능으로 확장하지 않는다.

#244는 정한 공식 자료의 실제 수집 확인, 독립 일정 CLI 구현, 공개 CLI와 외부 HTTP 경계의 회귀 검사·음성 대조로 완료를 평가한다. KIS 데이터 준비, 후보군 연결, 매수 추천 제품 인수는 후속 티켓에서 검증한다. 완전성 미입증을 독립 도구의 종료 차단으로 되살리지 않으며 다른 기능의 미완료를 #244 완료 관문으로 합치지 않는다. 일정 도구의 구현·검증이 남아 있으므로 이번 설계로 #244나 후속 제품을 완료 처리하지 않는다.

이번 확정 범위는 이 ADR과 관련 로컬 문서, #237·#239·#244·#245·#251의 로컬 이슈 수정안이다. 공용 검증 경계는 CLI 인수·stdout·stderr·종료 코드와 외부 HTTP이며 검토 기준은 `282cd886a4725eee0d95754391807c1733605012`와 확보한 이슈 원문이다. 코드 구현·커밋·푸시·원격 갱신·이슈 종료는 포함하지 않는다.
