# 상장 종목의 식별과 탐색 순위 누적은 공통 모듈이 소유한다

후보군 CLI와 유형 검증 CLI에서 반복하던 상장 종목 식별의 일관성 검사, 중복 제거, 원래 탐색 순위와 조회 출처 누적을 `ListedSecurities`가 소유한다. 호출자는 내부 지도와 배열을 수정하지 않고, 성공한 순위 묶음이 누적된 독립적인 snapshot을 받는다. 순위 묶음의 검증이 실패하면 증권과 출처 모두 반영하지 않는다.

KIS 조회·인증·실행 관측과 두 CLI의 탐색·검증·공개 오류 정책은 호출자에 남긴다. 후보군은 모든 행의 형식을 검사한 뒤 1위의 필수 필드와 식별 일관성을 검사하지만, 유형 검증 CLI는 행마다 형식과 선택 종목의 식별 일관성을 검사한 뒤 continuation을 검사한다. 선택한 행을 미리 배열로 완성하면 오류 우선순위가 바뀔 수 있으므로, 동기 callback 안에서 기존 순서대로 종목을 전달하고 callback이 정상 종료된 뒤에만 누적 상태를 반영한다. 고정 표본 평가 입력은 기존 경로를 유지한다.

[ADR 0011](0011-ranking-discovery-and-runtime-data-readiness.md)·[ADR 0014](0014-candidate-runtime-budget.md)의 첫 페이지·원래 순위·미보충 규칙과 [ADR 0017](0017-model-request-lifecycle.md)의 모델 요청 생명주기는 유지한다. 공개 검증은 기존 CLI의 인수·stdout·stderr·종료 코드와 외부 HTTP·시계 mock을 사용하며, 내부 배치나 snapshot 메서드에 테스트를 결합하지 않는다.
