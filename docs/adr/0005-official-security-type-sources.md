# 종목 유형 판별에 외부 공식 자료를 허용한다

[#250](https://github.com/mochafreddo/stock-scout/issues/250)의 2026-10-19 후속 설계 인터뷰에서 종목 유형과 해당 증권의 연결 근거에 거래소·발행사·규제기관의 공식 자료를 허용하기로 합의했다. 기존 조사에서 우선주 ADR·보통주 ADR·워런트가 같은 KIS 분류값을 반환하고 ETP 표시가 자료 간 충돌하여, KIS 전용 제약을 유지하는 단순함보다 적격 종목을 확인할 수 있는 근거의 범위를 넓히는 쪽을 선택했다. 시세·거래량·거래대금·순위의 공급자는 KIS로 유지한다.

첫 조사 범위는 로그인·유료 계약·새 자격 증명이 필요하지 않은 무료·공개 공식 자료다. 매일 사람이 종목별로 판정하거나 고정 허용 목록을 관리하는 방식 대신 자동 수집·연결·판별이 가능한 경로를 검증한다. 수동으로 확인한 표본은 자동 운영 가능성의 증거를 대신하지 않는다.

포괄적인 분류와 구체적인 유형은 그 차이만으로 충돌로 보지 않는다. 예를 들어 KIS의 `01=주식`과 같은 증권의 공식 보통주 표시는 양립할 수 있다. 같은 증권에 대한 구체적인 유형이 서로 모순되면 실제 충돌이며, 해결 근거가 없으면 유형 미확인으로 개별 제외한다.

외부 자료는 회사가 아닌 개별 상장 증권에 연결한다. 거래소·원본 종목 코드·주식 종류와 공식 식별 근거로 대응을 확인하며, 회사명이나 회사 단위 식별자만으로 합치지 않는다. 정상 조회에서 대응 종목을 찾지 못하면 유형 미확인으로 제외하고, 서로 다른 증권 중 어느 것인지 모호하면 기존 식별 실패 계약에 따라 전체 실패한다.

유형 자료는 실행마다 공식 출처에서 갱신하고 자료의 기준일과 적용 범위를 확인한다. 내려받은 시각만으로 현재 적용 가능성을 확정하지 않으며, 최신성을 확인하지 못한 자료나 이전 실행의 저장 자료로 성공 처리하지 않는다. 구체적인 유효기간은 출처 조사 결과에 따라 정한다.

구조화된 공식 목록과 필드부터 조사하고 필요하면 공식 페이지의 명시적인 유형 표시를 사용한다. LLM이나 이름·티커 추정 규칙 대신 코드로 공식 분류를 해석하며, ADR의 기초 주식이 보통주인지도 명시적인 근거로 확인한다.

해당 증권의 유형·연결·현재 적용 가능성을 확인할 수 있으면 공식 출처 하나로도 충분한 근거로 인정한다. 항상 두 출처를 요구하지 않지만 확인된 반대 근거는 해결해야 한다. 판별에 필요한 공식 자료의 조회·해석·최신성 확인에 실패하면 전체 실행을 실패시키며, 자료 장애를 유형 미확인이나 정상 빈 후보군으로 바꾸지 않는다.

다음 작업은 분류기 구현에 앞선 출처의 자동화 가능성 조사다. 무료·공개 공식 출처의 수집 방법, 증권 연결, 유형 표현, 최신성 확인, 이용 조건과 호출 부담을 확인한다. 기존 BBD/BBDO·ACONW/ADSEW·SPY/VXX 등의 반례로 적용 가능성을 확인하고 결과에 따라 채택 출처와 운영값을 정한다. 후보군 분류기 구현과 후속 차단 해제는 이 조사에 포함하지 않는다.

이 결정은 외부 자료를 활용한 자동 판별 가능성이나 검증 완료를 뜻하지 않는다. 채택 출처와 출처별 연결·최신성 확인 방법의 나머지 세부 사항은 후속 설계에서 정한다. 상위 명세의 변경 게시와 조사·구현·실연동 실행은 별도 단계이며, 기존 미검증 조건과 후속 구현 차단은 유지한다.
