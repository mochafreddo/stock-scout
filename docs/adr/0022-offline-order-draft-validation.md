# 주문 초안은 호출자가 제공한 일정으로 오프라인에서 검증한다

[#339](https://github.com/mochafreddo/stock-scout/issues/339)의 주문 초안 명령은 호출자가 제안한 주문 조건과 기존 `sessions` 결과를 받아 로컬에서 검증한다. 일정 조회를 별도 명령에 맡기면 초안 검증에 네트워크·인증·계좌 접근이 필요 없고, 같은 입력과 검증 시각으로 결과를 재현할 수 있다. 에이전트는 버전이 있는 초안 JSON에서 한 줄 검토 카드를 만들고, 사용자는 토스 앱에서 직접 입력·검토·제출한다.

## 첫 버전의 계약

- 대상 경로는 토스 앱의 미국주식 소수점 장 전 예약이다. 기존 `stock` 조회에서 확정한 심볼과 시장 `US`를 받고, 시장가 매수는 USD 금액, 시장가 매도는 주 수량을 받는다. 금액과 수량의 누락·동시 지정은 입력 오류로, 지정가·수량 매수·금액 매도는 미지원으로 구분한다. 관측 기준가와 그 기준 시각을 제공한 경우에는 체결가와 구분한다.
- 뉴욕 현지 거래일과 대상 정규장을 일정 결과와 대조한다. 거래일·세션 불일치, 정규장 일정 누락, 휴장은 구분한다. 호출자가 지정한 만료 시각은 오프셋을 포함하고 대상 정규장의 개장 시각 이하여야 한다. 검증 시각이 만료 시각에 도달하면 초안은 만료된다. 초안의 검토 기한과 앱의 예약 접수 마감은 별개다.
- 형식과 일정 검사를 통과한 초안은 앱의 종목별 예약 조건을 미확인으로 두고 `partial`·종료 코드 `2`로 반환한다. 에이전트는 카드 같은 줄에 `종목별 예약 조건 미확인 · 토스 앱에서 확인 후 직접 제출`을 표시한다. 초안을 반환할 수 없는 경우에는 사유별 `error`·종료 코드 `1`을 사용한다.
- 초안 명령의 외부 HTTP 전송은 0건이다. 사용자의 직접 제출 경로는 앱으로 한정한다. 초안·카드·검증 자료에는 계좌 식별자·토큰·자격 증명·실거래 원문을 포함하지 않는다. [#278](https://github.com/mochafreddo/stock-scout/issues/278)과 [#283](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791)의 조회·자료 전달 조건을 적용한다.

## 검토와 검증

검토 기준은 `ab3b4a1a0db5f3bb0dd061136a9430c321344a75`다. 실제 CLI 프로세스의 입력·stdout JSON·stderr·종료 코드와 HTTP 전송 여부를 합성 자료로 검증한다. 주문 방식별 정상 결과, 금액·수량 누락 및 동시 지정, 만료와 같은 순간, 일정 불일치·누락·휴장, 미지원 조합, 앱 조건 미확인, 민감 필드 미출력과 HTTP 전송 0건을 확인한다. CLI 레퍼런스와 에이전트 사용 지침에 JSON과 카드의 대응을 보여주는 합성 매수·매도 예제를 싣는다. 앱의 실제 예약 접수·체결 여부는 이 검증 범위 밖이다.
