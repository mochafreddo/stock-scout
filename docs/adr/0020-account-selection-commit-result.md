# 저장 완료한 기본 계좌 선택은 성공으로 반환한다

2026-11-15 검토 후속 설계에서 기본 계좌 선택은 저장 직전에 실행 마감을 확인하되, 성공적으로 저장을 마친 뒤에는 이후 마감 검사 때문에 실패로 뒤집지 않기로 했다. 저장한 뒤 `TIMEOUT`을 반환하면 소비자가 이전 계좌와 조회 범위가 유지됐다고 오해할 수 있으므로, 저장 완료 시 적용된 별칭·범위를 성공으로 반환하는 것을 우선한다. 저장 자체의 실패는 별도로 처리하고 이전 선택으로 자동 복구하지 않는다. 이는 모든 읽기 조회에 시간 상한을 없애는 결정이 아니며, 실제 계좌의 유효성 확인은 기존과 같이 이후 조회에서 수행한다. 이 결정은 합의한 설계이며 구현 완료를 뜻하지 않는다. 범위와 검증 계획은 [검토 후속 수정 설계](../review-remediation.md)를 따른다.
