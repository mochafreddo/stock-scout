# 조회 당시 순위로 탐색하고 실행마다 일봉 준비 여부를 검사한다

2026-10-26 #249의 후속 설계 인터뷰에서 개인용 CLI의 첫 단계에 맞게 조사 완료와 런타임 데이터 검사를 분리하기로 합의했다. 공식 자료 조사에서도 순위의 완료 정규장 대응·집계 범위·초기화 시점을 확인하지 못했으므로, 이를 입증할 때까지 기다리는 대신 조회 당시 KIS 순위를 종목 탐색에만 사용한다. 현재 관심 종목이 탐색에 섞이는 한계를 받아들이며 순위를 직전 정규장 분석값으로 사용하는 것은 금지한다.

NAS·NYS·AMS의 거래량·거래대금 여섯 탐색 순위는 첫 페이지에서 각각 최대 N개를 사용하고 원래 순위와 조회 시각을 남긴다. 제외·중복 제거 뒤 보충하거나 후속 페이지를 요청하지 않는다. 전체 시장 순위·목록의 완전성이나 공급자 최대 페이지 크기를 입증하지 않으며, N은 확보한 행 수와 도구 안전 한도 안에서 #251에서 결정한다. 비어 있지 않은 첫 페이지가 N보다 짧으면 있는 행만 사용하고 실제 수를 남긴다.

분석에는 공식 일정으로 정한 데이터 기준 세션 날짜와 필요한 과거 기간의 KIS 일봉을 사용한다. 공식 필드 정의에 따른 KIS 일봉 사용은 사용자가 승인한 운영 가정이며 정규장 전용 집계의 독립 입증이나 공급자의 보장으로 표현하지 않는다. 진행 중인 날짜의 행을 제외하고 필요한 날짜·기간·가격·거래량 필드를 검사한다. 현재의 수정주가 미반영 조건을 표시하고 미확인 단위·배율의 환산이나 서로 다른 기준의 수치 비교를 하지 않는다. 필수 데이터 누락과 여섯 순위 중 어느 하나의 빈 응답은 실행 전체를 자료 부족으로 종료하며 정상 빈 후보군·후보 없음으로 바꾸지 않는다. 정상 조회와 증권 유형 제외 후의 빈 후보군은 이와 구분한다.

고정 12:00·15:00 KST, 추가 날짜·예외 거래일의 관측이나 공급자 답변을 #249의 완료 조건으로 두지 않는다. 실행할 때 필요한 데이터의 준비 여부를 검사하고 준비 미확인이면 자동 대기·재관측 없이 종료한다. 한국 낮 전체의 이용 가능성을 보장하지 않으며, 공통 세션·공식 일정·장중 거부·출력 직전 개장 경계·인증·유형·비밀·비용 조건은 유지한다. 일정 등 별도 기능의 미완료를 #249의 종료 관문으로 합치지 않는다.

#249는 기존 여섯 순위·일별 시세 응답과 공식 조사로 조회 가능 범위를 확인하고, 탐색과 분석을 분리한 계약 및 첫 페이지 제한을 정하고, 미확인 사항과 중단 조건을 기록하면 조사 작업으로 완료를 평가한다. 데이터 의미를 입증하거나 날짜·필드 검사를 구현했다는 뜻은 아니다. 실제 런타임 검사와 공개 CLI·외부 HTTP 회귀 검사는 #245, N·기간·호출·실행 한도는 #251에서 정한다. 같은 성공 호출을 반복하거나 페이지·빈 응답 실연동을 위해 기다리는 조건을 후속 이슈에 다시 붙이지 않는다. 증거가 부족한 현상을 조사 완료로 소급 승격하지 않으며 과거 응답·실패·체크 이력은 보존한다.

이 결정은 ADR 0009, [설계 문서](../daytime-buy-candidate-design.md), [데이터 검증 문서](../kis-data-validation.md)의 완료 세션 순위·고정 시각 관측·지원 시간 사전 입증 및 페이지·정상 빈 응답 실연동 필수 조건을 해당 범위에서 대체한다. 설계 확정 단계에서는 로컬 문서와 #237·#239·#243·#245·#249·#251 이슈 수정안까지 작성하기로 했다. 공개 검증 경계는 CLI 입력·stdout·stderr·종료 코드와 외부 HTTP이며 검토 기준은 `97d85ac4ad6f125df58ab5684e69ea4776013045`와 확보한 이슈 원문이다. 그 단계의 승인에는 코드·실제 호출·커밋·푸시·원격 이슈 갱신·종료가 포함되지 않았다.
