# 검증한 후보군과 일봉으로 구독 매수 후보 보고서를 만든다

2026-10-28 [#240](https://github.com/mochafreddo/stock-scout/issues/240) 구현 전 사용자는 기존 후보군·인증·일정의 재사용, 최근 20개 완료 세션, 공통 600초 마감과 별도 추천 모델 최대 4회·180초를 승인했다. 공개 검증 경계는 CLI 인수·stdout·stderr·종료 코드와 외부 HTTP이며 검토 기준은 `be606f5a2981acd2c1e655b3c4771a35f3cde27d`이다. 승인에는 현재 main의 로컬 커밋과 실제 통합 실행 1회가 포함되며 푸시·원격 이슈 변경은 포함되지 않는다.

후보군 CLI와 매수 후보 CLI는 같은 후보군 수집 함수를 사용한다. 거래 일정·여섯 탐색 순위·상장 종목 중복 제거·유형 판단·필수 일봉 날짜와 필드 검사·개장 경계를 복제하지 않는다. 추천 모델에는 적격 종목 식별자와 두 세션을 주고, 네임스페이스가 있는 읽기 전용 도구로 이미 조회하고 검사한 KIS 일봉만 제공한다. 도구 호출 때문에 시세를 다시 조회하거나 원래 탐색 범위를 늘리지 않는다. 모든 적격 종목의 일봉을 읽은 뒤에만 후보 또는 후보 없음을 인정한다.

추천 모델은 최대 5개 종목, 선정 이유, 근거 관측 ID와 설명, 1~20개 정규장의 관찰 기간과 이유, 주요 위험을 제시한다. 이 기간은 관찰 설계값이며 충분한 분석 기간이나 자동 보유·청산 조건으로 입증한 값이 아니다. 코드는 종목과 관측 ID의 소속·중복·필수 항목을 검사하고 실제 KIS 값·출처·조회 시각을 복원한다. 회사명·기준 종가·세션·소수점 거래 미확인 안내를 모델에게 생성시키지 않는다. 단위가 확인되지 않은 환산과 수정주가 사용은 하지 않는다.

자유 서술의 근거 없는 뉴스·사건·수치·원인 설명과 장중 조건부 매수·매도·비중·체결 보장은 별도의 도구 없는 구독 요청으로 의미 검토한다. 이 검토도 같은 최대 4회·180초에 포함된다. 후보 선정에는 최대 3회만 허용하여 검토 요청 1회를 남기며 남는 예산을 다른 단계에 빌려주지 않는다. 의미 검토가 거부하면 보고서 전체를 실패 처리하고 자동 수정·재시도하지 않는다. 모델의 검토 통과는 의미적 정확도를 입증하지 않으며 `reliability: unverified`를 표시한다.

ADR 0014의 일정 모델 1회·유형 모델 12회·KIS 90회·발급 2회·일정 HTTP 100회·SIWC 갱신 2회는 유지한다. 추천의 별도 모델 요청 4회를 합치면 보고서 경로의 모델 전송 시도 상한은 17회다. 도구 읽기는 최대 12회이며 추가 외부 HTTP는 발생하지 않는다. 기존 구독 인증만 사용하고 구독 한도 소진·인증 실패·통신 실패에도 유료 API 요청을 보내지 않는다. 추천 인증 준비·도구·선정·의미 검토는 추천 단계 180초와 전체 600초·다음 개장 중 먼저 도달하는 마감에 함께 묶인다. 단계별 최대 시간을 모두 보장하는 정책은 아니다.

모든 모델 요청은 저장 비활성화와 스트리밍을 사용한다. 중간 도구 단계와 의미 검토를 포함한 각 요청에서 `response.completed`를 정확히 한 번 확인하고 스트림 끝까지 읽는다. 정상 JSON 뒤의 오류·중복 완료·불완전 응답·완료 없는 EOF·도구 실패·예산 소진은 완성된 보고서로 출력하지 않는다. 출력 직전에도 공통 마감·개장 경계와 비밀 포함 여부를 검사한다.

정상 후보 없음은 정상 빈 후보군을 포함해 종료 코드 0이다. 유형 판단의 분석 불충분은 2, 자료 누락·실행 제한·모델·인증 실패는 1이다. 공식 공지 완전성과 일정·유형·추천 의미 판단의 미검증 한계는 유지한다. 첫 실제 실행과 모의 회귀, 독립적인 추천 품질 및 제품 인수는 각각 구분한다.
