# 훅은 스냅샷의 lockfile로 개발 의존성을 준비한다

mise로 개발용 Node.js와 pnpm 버전을 고정하고, 커밋·푸시 대상의 의존성은 해당 스냅샷의 pnpm lockfile로 결정한다. pnpm의 심볼릭 링크를 포함한 작업 트리의 `node_modules`를 복사하면 스냅샷 밖의 의존성을 참조할 수 있으므로, 훅은 개발자가 준비한 로컬 pnpm 저장소에서 스냅샷에 오프라인으로 설치한다. 패키지 파일을 스냅샷으로 복사하고 설치 스크립트 실행을 비활성화하며, 설치가 실패하면 [기존 스냅샷 검사 정책](0004-staged-commit-validation.md)에 따라 커밋·푸시를 차단한다.
