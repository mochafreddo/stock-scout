# 완료 정규장 데이터로 다음 정규장의 매수 후보를 판단한다

2026-10-21 설계 인터뷰에서 사용자의 한국 낮 분석과 토스증권 소수점 예약 매수 흐름에 맞춰, 직전 완료 정규장 데이터를 기준으로 다음 정규장의 매수 후보를 판단하기로 합의했다. 뉴욕 거래일 자정부터만 실행하는 대신 완료 세션의 데이터 준비 이후 다음 개장 전까지 지원하며, 주말·휴장일도 검증된 다음 정규장을 대상으로 삼는다. 데이터 기준 세션과 판단 대상 세션을 분리하고 실제 지원 시간은 데이터 검증으로 확정한다. 이 결정은 ADR 0003의 뉴욕 자정 제한과 비거래일의 일률적 제외를 해당 범위에서 대체하며 공식 일정·변경 공지·공통 세션 검증은 유지한다.

종가 기준은 필요한 과거 일봉·거래량을 포함하며 진행 중인 세션의 수치를 섞지 않는다. 직전 완료 세션의 여섯 순위를 사용하는 기존 조건도 유지하고 충족할 수 없으면 탐색 방식을 별도로 결정한다. 보고서는 장중 조건부 주문에 의존하지 않는 매수 검토 후보를 제공하며, 기준 종가를 예약 주문 체결가격으로 제시하지 않는다.

사용자는 소수점 거래 가능 여부를 직접 확인해 예약한다. 증권 유형 적격성과 토스증권 거래 가능 여부를 분리하고 첫 버전은 거래 가능 여부를 미확인으로 표시한다. 자동 거래 가능 목록·토스증권 API·보유 내역 분석·매도 판단은 추가하지 않는다. 직접 확인이 필요한 불편을 받아들이고 계좌·주문 연동을 후속으로 둔다. 세부 계약은 [설계 문서](../daytime-buy-candidate-design.md)를 따른다.
