# 종목 유형 판단 실행 이력

> 이 문서는 제거된 KIS·내장 모델 제품의 당시 기록이다. 현재 제품은 [토스 전환 기록](toss-transition.md)을 따른다. 아래 명령·검증 결과는 당시 이력이며 현재 실행 안내가 아니다.

개별 실행의 결과와 당시 남은 조건을 기록한다. 현재 사용법과 검증 범위는 [종목 유형 판단 안내](llm-security-probe.md)를 참고한다.

## 2026-10-20 실행 상태

아래는 로그인 재개 전후의 실행 이력입니다. 현재 판단은 [현재 검증 상태](llm-security-probe.md#현재-검증-상태)를 따르세요.

### 로그인 재개 전 기록

공식 로그인 창을 한 번 열었지만 5분 안에 callback을 받지 못해 `siwc_login_timeout`으로 종료했습니다. 사용자는 원격 작업 중이므로 실제 로그인은 퇴근 후 진행하기로 했습니다. 이번 실행에서 토큰 교환·실제 구독 모델·검색 호출과 실제 유형 정확도 평가는 수행하지 못했습니다. 기존 Codex 인증을 대용으로 사용하거나 유료 API로 우회하지 않았습니다.

당시에는 로그인을 마치지 못해 구독 도구가 실제로 작동하는지 확인하지 못했고 표본 평가도 검증하지 못했습니다. 이후 로그인 재개 결과는 아래 별도 기록을 따르며, 로컬 검사와 음성 대조를 실제 호출 결과와 구분합니다.

### 로그인 재개 후 실제 검증
