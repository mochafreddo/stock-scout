# KIS 후보군 조회 설계

[상위 명세 #237](https://github.com/mochafreddo/stock-scout/issues/237)과 [작업 이슈 #239](https://github.com/mochafreddo/stock-scout/issues/239)를 구체화하는 설계 기록이다. 인터뷰가 진행 중이며 구현 시작을 위한 최종 합의는 아직 이루어지지 않았다.

## 합의한 사항

2026-10-17 설계 인터뷰에서 다음 사항을 확정했다.

- 후보군에는 기업 소재지와 관계없이 미국 거래소 상장 보통주와 식별 가능한 ADR을 포함한다. ETF·ETN·우선주·워런트와 유형을 확인할 수 없는 종목은 제외한다.
- 첫 버전은 미국 거래일의 정규장 개장 전 실행만 지원한다. 휴장일·장중·장 종료 후에는 지원 시간 밖임을 알리고 종료한다. 과거 날짜 지정은 지원하지 않는다. 구체적인 조회 가능 시간은 실제 KIS 데이터 검증 후 결정한다.
- 표준 출력은 후보군·데이터 기준 세션·근거 수치·제외 내역을 담은 JSON 하나다. 진행 상황과 오류는 표준 오류로 보낸다. 사람이 읽는 표 형식은 필요해질 때 추가한다.
- 중복 제거는 회사가 아닌 상장 종목 단위로 한다. 같은 종목이 두 순위에 나오면 하나로 합치되 두 순위의 순위·근거 수치를 보존한다. 같은 회사의 서로 다른 주식 종류나 ADR은 별도 종목으로 유지한다.
- 실연동 검증 자료는 필요한 응답 필드만 추려 조회 시각·요청 조건·공식 자료 출처와 함께 저장소에 남긴다. 인증 헤더·토큰·계좌 정보는 검증 자료로 수집하거나 기록하지 않는다. 실행마다 전체 응답을 보관하는 기능은 만들지 않는다.
- 시세·순위·종목 정보는 KIS만 사용한다. 거래일·개장·조기 폐장 일정에 한해 공식 거래소 자료를 허용하며 검증된 일정 범위 밖에서는 실행을 거부한다. 이는 상위 명세의 공급자 제한에 대한 명시적 예외다.
- 조회 대상은 KIS 거래소 코드 NAS·NYS·AMS로 한정하고 OTC는 제외한다. 거래소별 거래량·거래대금 순위를 합치되 원래의 거래소별 순위를 보존하며 통합 시장 순위를 만들지 않는다.
- 거래소별·순위별 상위 N개를 조회한 뒤 제외와 중복 제거를 수행한다. 제외된 종목을 아래 순위에서 보충하지 않는다. N은 실제 페이지 크기와 호출량을 확인한 뒤 확정한다.
- 여섯 순위가 모두 정상 조회되어야 실행 성공으로 인정한다. 하나라도 외부 오류·기준 세션 불일치·필수 데이터 누락이 있으면 전체 실패로 처리하며 부분 후보군을 정상 결과로 출력하지 않는다. 종목 유형을 식별하지 못한 경우는 개별 제외한다.
- 여섯 순위를 정상 조회한 뒤 모든 종목이 제외되면 빈 후보군으로 정상 종료하고 제외 이유를 출력한다. 이는 추천 분석의 결과인 후보 없음과 구분한다. KIS가 처음부터 빈 응답을 반환하면 정상적인 빈 결과라는 근거가 확인된 경우에만 성공으로 인정한다.
- 실행 시작 시 지원 시간을 검사하고 실행 제한 시간을 개장 시각 이내로 제한한다. 최종 결과를 내보내기 전에도 시각을 검사하며 개장 시각에 도달했다면 실행을 실패로 종료한다.

## 검증 상태

KIS 공개 예제에서 다음 사항을 확인했다. 이는 예제의 인터페이스와 필드 설명에 관한 근거이며 실제 응답의 의미를 검증한 결과는 아니다.

- [거래량 순위](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/trade_vol/trade_vol.py)와 [거래대금 순위](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/trade_pbmn/trade_pbmn.py)는 거래소 코드와 기간 조건을 받는다. 예제에는 특정 기준일이나 정규장 세션을 직접 지정하는 인수가 없다. 미국 거래소 코드로 NAS·NYS·AMS가 제시된다.
- [해외 종목 마스터](https://github.com/koreainvestment/open-trading-api/blob/main/stocks_info/overseas_stock_code.py)는 증권 유형·DR 여부·ETP 세부 유형을 구분한다. 이 필드만으로 보통주와 우선주를 구분하고 ADR의 후보군 적격성을 판단할 수 있는지는 미확인이다.
- [일별 시세](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/dailyprice/dailyprice.py)는 날짜·주기·수정주가 적용 여부를 받는다. 실제 응답의 정규장 범위는 미확인이다.
- [해외결제일자조회](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/countries_holiday/countries_holiday.py)는 결제일 조회로 설명된다. 이를 거래일·개장 시각·조기 폐장 시각의 근거로 사용할 수 있는지는 미확인이다.

Context7 조회는 `fetch failed`로 완료되지 않아 공식 KIS GitHub 자료를 확인했다. 실제 KIS 응답의 기준일·세션 범위·종목 유형 식별 가능성과 조회 가능 시간은 아직 검증하지 않았다. 조회 개수, 호출 횟수, 실행 시간 제한과 세부 오류 정책은 아직 확정하지 않았다.
