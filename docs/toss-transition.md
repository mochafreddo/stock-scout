# 토스 조회 도구 전환 기록

[#299](https://github.com/mochafreddo/stock-scout/issues/299)는 [#278의 통합 전환 명세](https://github.com/mochafreddo/stock-scout/issues/278)와 [#283의 계약](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791)에 따른 기존 제품 경로 제거다. 계획 기준 `ef64daa3d663e13af8e34001609aa5da4990dcc4`에서 착수 기준은 `aa914669a4d692891e3683112449149cca6b2512`로 바뀌었다. 착수 시 작업 트리는 깨끗했고 갱신한 `origin/main`과 HEAD가 같았다. 공개 검증 경계는 CLI 인수·stdout JSON·stderr·종료 코드·외부 HTTP다.

## 제거 전 확인한 관문

2026-11-10에 #294~#298의 본문·논의와 아래 저장소 기록을 확인했다. 티켓 종료만으로 모든 불확실성이 사라졌다고 판단하지 않으며 사용자 재결정과 관측 한계를 함께 적용한다.

| 관문 | 근거와 적용 범위 |
| --- | --- |
| 합성 검사 | [#295 연결 검증](toss-agent-validation.md), [#298 소비 검증](toss-agent-live-validation.md)의 실제 CLI·합성 HTTP 검사와 환경별 사용 근거를 확인했다. 과거 KIS·추천 검사 통과는 토스 검증으로 승계하지 않는다. |
| 실제 시장 조회 | [#296](https://github.com/mochafreddo/stock-scout/issues/296)과 [시장 기록](toss-market-validation.md)에서 첫 시장 도구 모음·봉 다음 페이지·비어 있지 않은 최근 체결 필드 대조를 확인했다. 거래 제약은 문서상 규칙·세션과 종목별 미확인을 제공하는 범위로 사용자가 재결정했다. |

위 재결정과 승인 범위 안에서 선행 관문이 충족되어 제거를 진행했다. 새 계좌·소비 환경·자료 처리 범위의 승인을 이 기록으로 확대하지 않는다. #278 본문과 종료 상태는 변경하지 않는다.

## 제거와 보존 범위

KIS 인증·조회·프로브·관측, 여섯 순위 후보군과 완료 일봉 공통 관문, 추천 CLI, 유형 웹 검색, 내장 유형·일정·추천·의미 검토 모델, 전용 구독 인증·갱신·유료 전환·비용 제한의 런타임 20개와 관련 테스트·도우미·mock·일정 fixture 31개를 제거했다. 이 검사 제거의 근거는 #278의 명시적 제품 제거 결정이며 새 토스 조회 계약의 검사를 약화하지 않는다. `ai`·`@ai-sdk/openai`와 전용 전이 의존성은 manifest·lockfile에서 제거했다. 개발용 TypeScript·Biome·Node 타입은 유지한다.

진입점은 [scripts/toss.ts](../scripts/toss.ts)다. 토스 런타임 11개와 토스 테스트·도우미 13개의 내용, 공통 검증 훅·사전 검사와 그 테스트를 착수 기준 그대로 유지했다. 토스 런타임의 import는 Node 표준 라이브러리와 토스 모듈뿐이다. 현재 호출자·테스트·manifest·lockfile을 검색한 범위에서 KIS·내장 모델 의존성은 남지 않는다. 이 저장소 검색은 저장소 밖 소비자의 부재를 입증하지 않는다.

토스의 안전한 오류 코드·공급자 요청 식별자·조회 시각·실행 및 HTTP 한도 진단은 기존 공통 클라이언트와 JSON 계약으로 유지한다. 제거된 KIS 실행 관측 파일의 호환 계층이나 자동 복귀는 제공하지 않는다. 실제 인증 저장소·환경 파일·기존 관측 파일을 삭제하거나 이전하지 않는다. 기존 로컬 설치의 미사용 패키지 정리를 위한 설치·prune은 실행하지 않았다.

README·시작 안내·문서 색인·용어집·에이전트 지침을 현재 조회 제품으로 정리했다. [ADR 0019](adr/0019-toss-query-tools-transition.md)는 기존 ADR의 대체 관계를 기록한다. 과거 제품 안내·인수·연구·증거와 기존 보고서 용어는 이력으로 보존하며 제거된 소스 링크는 착수 기준의 고정 리비전을 가리킨다. #237과 과거 인수 결과를 새 제품의 검증으로 바꾸지 않는다.

## 최종 검증과 실검증 영향

이번 변경은 기존 경로와 전용 의존성 제거 및 문서 전환이다. 실제 조회를 담당하는 토스 소스·합성 HTTP fixture·공개 CLI 검사·공통 실행 제한은 변경하지 않았다. 앞선 실검증 이후 달라진 런타임 의존성을 추적해 토스가 제거 대상 모듈이나 AI SDK를 사용하지 않음을 확인했다. 최종 체크아웃에서는 명령 발견·합성 시장 및 계좌 조회·부분 페이지·오류를 기존 공개 경계 검사로 다시 확인한다.

이번 작업에서 추가 실제 토스 조회·계좌 접근·자료 전달은 수행하지 않는다. 토스 조회 경로가 그대로라는 소스 비교와 최종 합성 검사에 근거해 기존 #296~#298의 실검증을 연결한다. 실서비스 전체 시장·시간대의 가용성, 모든 주문 상태·업무 사건, 봉 최종 확정·종목별 거래 적격성이나 추천 품질을 추가 입증한 결과는 아니다. 조건 주문 다음 페이지와 진행 중 주문의 미관측 항목은 기존 기록대로 유지하며, 승인된 후속 조회에서 표본을 확보하면 대조한다.

최종 로컬 검사 결과와 리뷰·커밋은 작업 완료 보고에서 구분한다. Actions 활성화·배포·자동매매·새 MCP 또는 HTTP 서버는 추가하지 않았다.
