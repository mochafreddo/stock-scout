# 가격 시각·일봉 날짜 선택·묶음 조회 개선 설계

2026-11-12~13의 설계 합의와 후속 구현을 연결하는 기록이다. 현재 인수·JSON·한도·오류 계약은 [CLI 레퍼런스](toss-cli.md), 소비 절차와 보고서 가격 분류는 [에이전트 사용 지침](toss-agent-usage.md), 용어 정의는 [용어집](../GLOSSARY.md)을 따른다. 이 문서는 해당 계약을 별도로 유지하지 않는다.

제품 책임 경계는 [#278](https://github.com/mochafreddo/stock-scout/issues/278), [#283의 결정](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791), [전환 기록](toss-transition.md)을 따른다. 세부 설계 원문은 [축약 전 고정 리비전](https://github.com/mochafreddo/stock-scout/blob/3714f59e0ef1edef20c9b63b833d8114f5ef755a/docs/query-improvements.md)에 보존한다.

## 2026-11-12 설계 합의

사용자는 Q1~Q11에서 가격 시각 경과 시간·경고, 미국 일봉 기준 거래일 선택, 순차 일봉 묶음 조회와 공통 실행 예산 확장을 확정했다. 당시 검토 기준은 `7309063b8dcd023e53f5cebf12e4bacd551d4ed3`과 설계 합의였고, 설계 변경은 GLOSSARY.md·이 문서·문서 색인의 링크에 한정했다.

| 선택 | 이유와 경계 |
| --- | --- |
| 가격 경과 시간과 경고를 제공 | 조회 시점의 해석을 돕되 공급자의 지연·실시간성·동일 시점 스냅샷을 보장하지 않는다. 유효한 가격은 경고만으로 제외하지 않는다. |
| 미국 일봉의 기준 거래일을 포함하는 상한 | 날짜 선택을 봉 완료 확인과 구분한다. 공급자 timestamp의 표시 날짜나 티커 모양으로 미국 거래일·시장을 추정하지 않는다. |
| 요청 순서대로 한 페이지씩 묶음 조회 | 공통 예산과 호출 간격 안에서 종목별 결과를 보존하고, 후속 페이지는 소비자가 선택한다. 자동 파일 저장·디스크 재개 상태는 추가하지 않는다. |

검증 계획의 공개 경계는 실제 CLI 인수·stdout JSON·stderr·종료 코드와 외부 HTTP였다. 합성 검사는 가격 임계값 전후·일치 및 시각 누락·null·미래, 미국 거래일·서머타임·휴장일과 시장 확인, 공급자 페이지 경계, 묶음 순서·공통 예산·부분 결과·중단 시 결과 보존을 대상으로 정했다. 중요한 검사는 결함을 잡는 음성 대조를 남기고 실제 공급자 관측과 구분하기로 했다.

설계 확정은 코드 구현·실제 토스 및 계좌 조회·인증 변경·GitHub 게시·커밋·푸시의 승인이 아니었다. 설계 작업에서는 코드 테스트와 실제 토스 조회를 실행하지 않았다. 날짜 선택과 봉 완료 확인의 구분은 [ADR 0019](adr/0019-toss-query-tools-transition.md)의 기존 경계와 일치해 새 ADR을 만들지 않았다.

## 2026-11-13 사용 후 개선 설계

사용자는 Q1~Q7의 권고안을 수락하고 Q8에서 전체 범위·공개 검증 경계·검토 기준을 확정했다. 구현 명세는 [#305](https://github.com/mochafreddo/stock-scout/issues/305)에 게시했다. 당시 검토 기준은 `e96b1e7e64c468378242f3466ec9a8fef049f3fb`과 설계 합의였다.

| 선택 | 이유와 경계 |
| --- | --- |
| 보고서 시점에 참고가·시점 미확인 가격 분류 | 분석 중 지난 시간을 반영한다. 분류는 소비 에이전트가 맡고 CLI가 외부 보고서의 준수를 보장하지 않는다. |
| 기존 합성 실행기에 일봉·묶음 사례와 소비 예시 추가 | 실제 분석에 사용할 동일한 코드의 필드 매핑을 독립 기대값으로 확인한다. 스키마 사본·새 분석 엔진을 만들거나 실제 조회마다 검사를 강제하지 않는다. |
| 일봉 묶음의 종목별 반환 요약 | 요청량과 실제 반환 범위를 구분한다. 추가 HTTP 없이 확보된 시장·시간대 근거만 사용하고 봉 완료·최종 확정·분석 충분함은 보장하지 않는다. |

구현 범위는 에이전트 지침·CLI 문서, 기존 합성 실행기의 일봉·묶음 사례, 묶음 반환 요약과 검사였다. 외부 소비 저장소의 분석 코드나 새 보고서 생성기는 포함하지 않았다.

공개 검증 경계에는 합성 출력을 입력받는 소비 코드도 포함했다. 독립된 기대값과 잘못된 필드 접근의 음성 대조, 미국 거래일·서머타임과 시간대 미확인, 빈 결과·부분 페이지·오류·미조회, 추가 HTTP 부재, 보고서 시점의 가격 분류를 확인하기로 했다. 회귀 검사는 수정 전 실패를 확인하고 실행 코드 변경 뒤 검토·단순화와 로컬 필수 검사를 수행하는 계획이었다.

설계 확정 당시 실행 코드·실제 토스 및 계좌 조회·인증 변경·GitHub 게시·커밋·푸시는 수행하지 않았다. 새 ADR을 추가하지 않고 기존 제품 책임 경계를 유지했다.

### 구현 상태 (2026-11-13)

위 설계의 구현은 `main`에 반영됐다. [#305](https://github.com/mochafreddo/stock-scout/issues/305)와 하위 이슈 #306·#307·#308은 종료됐으며, 관련 변경은 다음과 같다.

- [#306](https://github.com/mochafreddo/stock-scout/issues/306): [27d907a](https://github.com/mochafreddo/stock-scout/commit/27d907a)에서 참고가·시점 미확인 가격 지침과 실행 가능한 [가격 소비 예시](../examples/price-consumer.mjs)를 추가했다.
- [#307](https://github.com/mochafreddo/stock-scout/issues/307): [86fb146](https://github.com/mochafreddo/stock-scout/commit/86fb146)에서 일봉 묶음의 종목별 반환 요약과 관련 검사를 추가했다.
- [#308](https://github.com/mochafreddo/stock-scout/issues/308): [ffaebfd](https://github.com/mochafreddo/stock-scout/commit/ffaebfd)에서 기존 합성 실행기에 일봉·묶음 사례와 실행 가능한 [일봉 소비 예시](../examples/candle-consumer.mjs)를 추가했다. 이후 [f30da62](https://github.com/mochafreddo/stock-scout/commit/f30da62)에서 소비 예시의 입력 검증을 재사용하도록 정리했다.
- [c903858](https://github.com/mochafreddo/stock-scout/commit/c903858)에서 공통 조회 중단 정책을 클라이언트로 모으고 날짜 선택 묶음의 인증·권한 오류 회귀 검사를 추가했다.

현재 사용 절차와 출력 계약은 [에이전트 사용 지침](toss-agent-usage.md)과 [CLI 레퍼런스](toss-cli.md)를 따른다. 이 문서는 설계 합의와 구현 연결을 보존하며 현재 계약을 별도로 유지하는 문서로 사용하지 않는다.

#305의 구현 완료 댓글은 합성 CLI·HTTP·시계 및 로컬 코드 검증 결과를 기록한다. 그 결과를 실제 토스·계좌 조회, 실제 자료의 외부 모델 전달, 공급자 스키마 일치나 모든 소비 에이전트의 준수 보장으로 확대하지 않는다. 이번 문서 반영에서도 실서비스 조회와 인증 변경은 수행하지 않는다.
