# 가격 시각·일봉 날짜 선택·묶음 조회 개선 설계

이 문서는 2026-11-12 설계 논의의 Q1~Q11에서 사용자가 최종 확정한 후속 개선 요구사항이다. 현재 구현의 동작 설명이 아니며 코드 구현·실제 토스 조회·GitHub 게시를 승인한 기록도 아니다. 기존 제품 계약은 [#278](https://github.com/mochafreddo/stock-scout/issues/278), [#283의 결정](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791), [전환 기록](toss-transition.md)을 따른다. 용어는 [용어집](../GLOSSARY.md)을 따른다.

## 가격 시각 경과 시간과 경고

현재가 조회에 종목별 원천 시각 기준 경과 시간과 오래됨 경고를 추가한다. 기준 시각은 결과의 조회 시각이며 공급자 시각의 누락과 null은 원래 구분을 보존한다. 누락·null·미래 시각은 경과 시간과 오래됨 판정이 불가한 이유를 표시한다. 조회 시각으로 원천 시각을 채우지 않는다.

기본 임계값은 900초이며 호출별로 변경할 수 있다. 경과 시간이 임계값을 초과하면 경고하고 같은 값이면 초과가 아니다. 이는 사용 편의를 위한 기준이며 공급자의 지연 보장·실시간성·동일 시점 스냅샷을 뜻하지 않는다. 임계값 이내를 최신 또는 실시간으로 표시하지 않는다. 경고나 판정 불가만으로 유효한 가격을 제외하거나 조회 상태를 부분 결과로 바꾸지 않는다.

## 일봉 기준 거래일

첫 지원 범위는 미국 종목 일봉이며 지정한 거래일을 포함하는 상한을 제공한다. 한국 시각으로 표현된 공급자 timestamp의 날짜 부분을 그대로 미국 거래일로 쓰지 않는다. 날짜 생략 시 기존 최신 봉 조회를 유지하며 오늘 자동 제외·마지막 완료 거래일 추정은 하지 않는다.

날짜 옵션을 사용할 때 공급자 종목 정보를 추가 조회하여 미국 시장 여부를 확인한다. 티커 모양으로 시장을 추정하지 않는다. 식별이 모호하거나 미국 시장으로 확인하지 못한 종목은 해당 일봉 조회를 진행하지 않고 이유를 반환한다. 추가 조회·인증·재시도는 해당 실행 예산에 포함한다. 날짜 옵션이 없는 기존 조회에는 이 확인을 추가하지 않는다.

날짜 옵션과 기존 before를 함께 입력하면 외부 호출 전에 입력 오류로 처리한다. 첫 페이지에는 날짜 옵션을 사용하고, 후속 페이지에는 공급자가 반환한 nextBefore를 기존 before에 그대로 전달한다. 경계에 임의 시간 차감을 적용하지 않는다. 묶음 결과에도 종목별 다음 경계를 반환하고 후속 페이지는 해당 종목의 개별 명령으로 조회한다.

휴장일을 지정하면 그날 이하에서 존재하는 봉을 조회한다. 종목당 기존 count 범위의 한 페이지만 요청하며 추가 페이지를 자동 조회하거나 필터 후 개수를 채우기 위한 추가 요청을 하지 않는다. 다음 페이지·페이지 미확인·잘못된 항목은 기존 부분 결과 계약을 따른다. 반환 개수는 완료 거래일 수를 보장하지 않는다. 각 봉의 completion과 inProgress는 unknown으로 유지한다.

## 일봉 묶음 조회

명시적인 읽기 전용 묶음 명령으로 최대 20종목을 요청 순서대로 조회한다. 시간 상한은 120초, HTTP 전송 상한은 40회이며 먼저 도달한 상한에서 중단한다. 인증·재시도도 전송 횟수에 포함하고 잠금·호출 간격·재시도 대기를 전체 시간에 포함한다. 개별 HTTP 최대 15초·남은 시간 준수·프로세스 간 공통 최소 1초 간격과 더 엄격한 공급자 제한을 유지한다. 기존 단일 조회의 60초·10회 제한은 유지한다. 이 값은 실행 제한이며 완료 시간의 관측값이나 보장이 아니다.

입력 형식 오류·중복 심볼은 첫 외부 호출 전에 거부한다. 종목 부재·개별 응답 형식 오류·개별 조회 실패는 기록하고 다음 종목으로 진행한다. 인증 복구 후에도 실패하거나 권한·IP 제한을 확인하면 남은 조회를 중단한다. 호출 제한은 기존 재시도 정책과 남은 실행 예산을 따른다. 종목마다 한 페이지만 조회한다.

stdout에는 요청 순서대로 종목별 성공·부분 결과·오류·미조회 사유를 포함하는 JSON 하나를 반환한다. 한도 도달이나 처리 가능한 중단 신호에서는 확보한 결과를 보존한다. 자동 파일 저장·디스크 재개 상태는 추가하지 않으며 강제 종료·프로세스 충돌 후 복구를 보장하지 않는다. 사용자가 stdout을 파일로 저장할 수 있다.

## 확정한 후속 구현과 검증 범위

대상 저장소는 stock-scout 하나다. 후속 구현 범위는 현재가 경과 시간·경고, 미국 일봉 기준 거래일 선택, 순차 일봉 묶음 조회, 공통 실행 예산의 확장과 관련 CLI 도움말·사용 지침·검사다. 기존 단일 조회·프로세스 간 호출 간격·안전한 오류·출력 가림 계약을 보존한다. 묶음의 집계 상태와 종료 코드는 기존 success=0·partial=2·error=1의 의미에 맞추며 정상 빈 자료와 실패를 구분한다.

검토 기준은 논의 착수 HEAD인 7309063b8dcd023e53f5cebf12e4bacd551d4ed3과 이 문서의 최종 합의 내용이다. 설계 작업의 변경 범위는 GLOSSARY.md의 용어 추가, 이 설계 문서, docs/README.md의 설계 링크다. 구현 착수 시 현재 HEAD·작업 상태·원격을 다시 확인하며 동시 작업을 포함하거나 되돌리지 않는다.

공개 검증 경계는 실제 CLI 인수·stdout JSON·stderr·종료 코드와 외부 HTTP 요청이다. 네트워크·시계·외부 서비스를 대체하는 합성 검사로 다음을 확인한다.

- 가격 경과 시간의 임계값 전후와 일치, 호출별 임계값 변경, 원천 시각 누락·null·미래 시각, 경고만으로 부분 결과가 되지 않는 동작.
- 미국 거래일과 한국 표시 날짜가 다른 사례, 뉴욕 서머타임 경계, 기준일 포함, 휴장일·정상 빈 결과, 날짜·before 동시 입력 거부, 공급자 다음 경계 보존, 완료 여부 unknown 유지.
- 미국 시장 확인·식별 모호함·미국 외 시장·확인 실패, 추가 조회의 예산 포함, 날짜 옵션 생략 시 기존 요청 흐름 유지.
- 12종목 순차 조회, 최대 20종목·120초·40회 전송과 인증·재시도 포함, 기존 공통 간격·개별 HTTP 상한 유지, 입력 오류·중복 심볼의 호출 전 거부.
- 종목별 부분 페이지·오류·미조회 사유와 요청 순서, 공통 접근 실패 시 중단, 처리 가능한 중단 신호에서 결과 보존, 정상 빈 자료와 실패 구분.

중요 검사는 잡으려는 결함으로 실패하는 음성 대조를 확인하고 실제 공급자 관측과 구분한다. 최종 변경을 검토·단순화한 뒤 저장소가 요구하는 로컬 검사를 수행하는 것이 후속 구현의 검증 계획이다. 이 설계 작업에서는 코드 테스트·실제 토스 조회를 실행하지 않는다.

이번 합의는 설계 확정이다. 코드 구현·실제 토스 및 계좌 조회·인증 변경·GitHub 게시·커밋·푸시는 별도 요청 전까지 수행하지 않는다. 새 ADR은 만들지 않는다. 날짜 선택을 봉 완료 확인과 구분하는 경계는 ADR 0019의 기존 결정과 일치하며 이번 실행 상한은 별도의 장기 구조 결정을 요구하지 않는다.
