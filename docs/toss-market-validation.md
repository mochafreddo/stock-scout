2026-11-08~10의 시장 조회 기록이다. 초기 보류 뒤 [비어 있지 않은 최근 체결 대조](#2026-11-10-비어-있지-않은-최근-체결-대조)에서 남은 조건을 충족한 것으로 평가했다. 후속 소비 환경 검증과 기존 경로 제거는 [전환 기록](toss-transition.md)을 따른다. 아래 관측은 각 실행 시점의 근거이며 이후 기능 전체의 실검증을 뜻하지 않는다.

## 승인과 실행 조건

사용자는 이번 대화에서 기존 로컬 인증 재사용, 아래 시장 조회와 실제 다음 페이지 조회, 원응답의 비공개 대조 및 금융 원문·비밀 없는 결과 기록을 명시적으로 승인했다. [#294의 접근 준비](toss-access-readiness.md)에 기록한 공식 AI 활용 안내에 따른 사용자 재결정과 공급자 조회 전용 권한의 미확인은 유지한다. 이번 승인이 자료별 학습·장기 보관 조건이나 공급자의 권한 차단을 입증하지는 않는다.

기존 보호 위치의 실행기와 인증을 재사용했다. 실행기·디렉터리의 0700, 자격 증명·상태 파일의 0600을 확인했으며 자격 증명 값은 출력하지 않았다. 계좌 선택·허용 범위 변경, 계좌 조회, 키 발급, 주문 제출·정정·취소, 장애 유발은 수행하지 않았다.

실제 조회는 2026-11-08 22:16:02~22:16:20 KST에 16회, 페이지 전송 인수의 추가 확인은 22:17:03~22:17:07 KST에 4회 수행했다. 출력 가로채기 없는 실제 stdout 검사는 22:20:39~22:20:57 KST에 같은 명령·페이지 조합으로 16회 수행했다. 미국 시장의 일요일 관측이며 장중 가용성 검증이 아니다. 세션과 거래 제약에는 미국 현지 날짜 `2026-11-06`을 명시했다.

## 대조 방법과 문서 근거

공개 검증 경계는 CLI 인수·stdout JSON·stderr·종료 코드·외부 HTTP다. 첫 20회는 실제 CLI 하위 프로세스에서 실제 HTTP를 통과시키고 응답 복사본과 출력 함수에 전달된 직렬화 JSON을 메모리 안에서 비교했다. 이때 stdout은 대조 요약으로 바뀌므로 소비자가 받는 실제 출력 경로의 근거로 사용하지 않았다. 리뷰 후 별도 16회는 출력 함수를 바꾸지 않고 실제 stdout 파이프를 메모리로 받아, 한 줄의 JSON·version·자료 배열·상태·종료 코드·빈 stderr를 확인했다. 두 방식의 관측 시점은 다르며 동일 스냅샷이라고 주장하지 않는다.

반환한 자료 필드의 값·순서·소수 문자열·통화·시각 보존을 대조했으며 응답 본문 전체나 가격·수량·금액, 키·토큰·계좌 식별자는 증거 파일에 저장하지 않았다. 결과 기록에는 명령, 실행 시각, 상태·종료 코드, 자료 개수, 누락 사유, HTTP 경로·상태, 대조 결과 및 출처 메타데이터·공급자 순위 집계 시각·선별한 페이지 요청 인수가 남았다. 가격·거래량 자료 행은 보관하지 않았으며 실제 다음 봉 경계는 저장하지 않고 일치 여부로 기록했다. 인증 응답은 대조·기록 대상에서 제외했다.

2026-11-08에 다시 수집한 [공식 REST OpenAPI](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)는 1.2.28이었다. [공식 FAQ](https://developers.tossinvest.com/docs/faq)의 봉 시각 설명도 대조했다. 데이터의 문서상 의미는 [CLI 레퍼런스](toss-cli.md)에 연결하고, 다음 표에는 이번에 실제 확인한 범위만 기록한다. 문서상 세션 범위가 개별 체결의 원천 거래소나 봉의 최종 확정 여부까지 실증된 것은 아니다.

일봉과 분봉은 `next_page` 때문에 부분 결과였다. 추가 4회 관측에서 각각 첫 페이지의 다음 경계를 후속 HTTP의 `before`로 정확히 전달한 것을 확인했다. 1밀리초 차감·마지막 봉에서 경계 재계산·자동 중복 제거는 적용하지 않았다. 반환 건수로 마지막 페이지를 추정하지 않았으며 마지막 페이지·빈 페이지 뒤 다음 페이지는 이번에 실관측하지 않았다.

일봉의 현지 자정 시각, 정규장 OHLC와 시간외를 포함할 수 있는 종합 거래량의 구분, 분봉 종료 경계, 증권 수량 및 통화별 가격 단위는 공식 문서와 CLI 표시를 대조했다. `completion`·`inProgress`·최신성과 보장되지 않은 세션은 계속 `unknown`이며, 문서상 의미와 이번 자료 보존 확인을 봉 최종 확정의 실증으로 확대하지 않는다.

## 합성 검사와 결함 여부

기존 시장 CLI의 합성 검사 67개가 통과했다. 실행 명령은 다음과 같으며 네트워크·시계를 대체하는 검사이므로 실제 토스 호환성의 근거와 구분한다.

```sh
node --test tests/toss.test.mjs tests/toss-stock.test.mjs tests/toss-discovery.test.mjs tests/toss-market.test.mjs tests/toss-candles.test.mjs tests/toss-sessions.test.mjs
```

이번 표본에서는 제품 코드 수정이 필요한 불일치를 발견하지 않았다. 제품 코드·기존 합성 검사 변경과 새 회귀 테스트는 없으며, 수정 전 실패를 제시할 버그 수정도 없다. 정상 빈 결과·오류·잘못된 응답·한도·중단 등의 기존 합성 검사를 실서비스 장애 유발로 재현하지 않았다. 전체 로컬 회귀 검사와 문서 검사의 최종 결과는 이 변경의 커밋 보고에 별도로 남긴다.

## 인수 판단과 재개 조건

[#296](https://github.com/mochafreddo/stock-scout/issues/296)은 보류한다. 승인된 시장 조회, 네 종류 순위, 실제 일봉·분봉 페이지와 의미 대조의 근거를 확보했지만, 비어 있지 않은 최근 체결 사례와 종목별 거래 제약의 직접 조회 근거는 확보하지 못했다. 최근 체결은 특정 사례 미관측이며 기능 미지원으로 판정하지 않는다. 종목별 제약 조회는 공식 API 미제공이며 단순히 이번 표본에 없었던 경우와 구분한다.

위 보류 판단은 아래 요구 범위 재결정 전의 실행 당시 기록이다.

### 2026-11-08 요구 범위 재결정

사용자는 첫 버전의 거래 제약 기능을 공식 문서상 규칙과 세션을 제공하고, 종목별 거래 가능 여부·수량·금액·앱 조건의 미확인을 표시하는 범위로 인수하기로 합의했다. `partial`과 미확인 표시는 유지하며 종목별 확정 정보의 직접 조회는 시장 조회 인수의 필수 조건에서 제외한다. 실제 거래 전 종목별 조건은 사용자가 확인한다. 이는 필요한 기능 범위의 변경이며 종목별 조회 성공이나 거래 가능의 입증이 아니다.

비어 있지 않은 최근 체결의 가격·수량·통화·시각 대조는 필수 완료 조건으로 유지한다. 따라서 #296은 계속 보류하며 열린 상태로 둔다. 체결 자료가 제공되는 시간에 승인 범위 안에서 다시 확인하고, 빈 응답만 받으면 미관측으로 남긴다. 정상 빈 결과와 합성 검사 통과로 실제 체결 항목의 대조를 대신하지 않는다.

이번 재결정에서는 제품 코드 변경이나 추가 실제 조회를 수행하지 않았다. 기본 인증·권한·자료 전달 조건이나 소비 환경이 달라지면 해당 범위부터 다시 확인한다. 한 번의 성공을 전체 시장·시간대·영구 가용성으로 일반화하지 않는다.

### 2026-11-08 최근 체결 재확인

사용자의 후속 구현 요청에 따라 기존 승인된 인증과 시장 조회 범위로 `trades AAPL 5`를 한 번 재확인했다. 검토 기준은 `ecd7b9d6c4e14e22fce55a64382e7d90c40515a4`이며 실행은 23:58:41~23:58:42 KST에 이루어졌다. 공급자는 HTTP 200과 정상 빈 배열을 반환했고 CLI는 `success`·종료 코드 0·빈 stderr를 반환했다.

실제 HTTP 응답 복사본과 변경하지 않은 stdout을 별도 파이프로 메모리에 받아 항목 수와 가격·수량·통화·시각의 보존을 대조했다. 원자료는 파일에 저장하지 않았으며 체결 원자료를 제외한 실행 시각·상태·항목 수·대조 결과를 남겼다. 대조기는 합성 항목의 네 필드와 항목 수를 각각 바꾼 다섯 사례를 거부했다. 실제 응답은 빈 배열이므로 항목 필드의 실자료 보존은 이번에도 미관측이며, 합성 대조기 검사로 이를 대신하지 않는다.

제품 수정이 필요한 불일치는 발견하지 못했다. 비어 있지 않은 체결 항목의 대조가 남아 #296은 계속 보류한다. 이번 재확인 역시 미국 시장의 일요일 관측이며, 체결 자료가 제공되는 시간의 관측을 대신하지 않는다.
