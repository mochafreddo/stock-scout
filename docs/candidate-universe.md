# 후보군 제품 기록

이 문서는 제거된 KIS·내장 모델 제품의 후보군 수집 흐름과 한계를 보존한다. 현재 제품은 [토스 전환 기록](toss-transition.md)을 따른다. 당시 명령·인증·출력·오류 계약은 [제거 전 실행 안내](https://github.com/mochafreddo/stock-scout/blob/aa914669a4d692891e3683112449149cca6b2512/docs/candidate-universe.md)에 남아 있으며 현재 체크아웃의 실행 안내가 아니다.

## 당시 역할과 결정

공식 거래 일정, KIS 탐색 순위·일봉과 내장 모델의 증권 유형 판단을 연결했다. 후보군 수집 자체는 매수 후보 선정·추천을 하지 않았으며, [매수 후보 보고서](buy-candidates.md)가 같은 수집 경로를 사용했다. [#245](https://github.com/mochafreddo/stock-scout/issues/245)의 구현 결정은 [ADR 0011](adr/0011-ranking-discovery-and-runtime-data-readiness.md)부터 [ADR 0014](adr/0014-candidate-runtime-budget.md)까지의 후속 합의를 따랐다.

- 공식 연간 일정과 제한된 공지로 세 거래소의 공통 데이터 기준 세션과 다음 판단 대상 세션을 정하고 장중 실행을 거부했다.
- NAS·NYS·AMS의 거래량·거래대금 여섯 순위에서 첫 페이지 상위 1개씩 탐색했다. 제외·중복 제거 뒤 다른 종목으로 보충하지 않았다.
- 상장 종목별로 중복을 제거하고 보통주·보통주 성격 ADR을 포함했다. 서로 다른 주식 종류·ADR은 별도 종목으로 취급하고 미확인·비적격 종목은 이유와 함께 제외했다.
- 포함 종목의 최근 20개 완료 세션에 해당하는 KIS 일봉을 검사했다. 필수 일봉이 부족하면 페이지를 늘리거나 기간을 줄이지 않았다.
- 전체 600초와 다음 정규장 개장 중 이른 마감을 적용했다. 정상 빈 후보군과 모든 종목을 확인하지 못한 분석 불충분을 구분하고, 실패한 부분 후보군을 정상 결과로 내보내지 않았다.

## 검증 근거와 한계

순위는 조회 당시의 탐색 자료이며 완료 세션 순위나 전체 시장 순위가 아니었다. 일봉은 공식 필드 정의에 따른 승인된 운영 가정으로 사용했고 수정주가를 반영하지 않았다. 정규장 전용 집계, 공식 공지 수집 완전성과 모델의 의미적 신뢰도는 독립적으로 입증하지 못했다.

외부 통신·시간을 대체한 CLI 검사는 실제 공급자 의미·모델 정확도·실제 후보군 실행의 검증과 구분한다. 선행 근거는 [KIS 검증 기록](kis-data-validation.md), [일정 검증 기록](market-calendar-validation.md), [유형 표본 평가](security-type-evaluation-samples.md)에 있다. 보고서가 같은 수집 경로를 실제 사용한 범위는 [첫 버전 인수 기록](first-version-acceptance.md#2026-11-03-한국-낮-통합-실행)에 있으며 독립 후보군 CLI의 실행 기록과 구분한다.

한국 낮 전체의 데이터 가용성이나 토스증권 거래·예약·체결은 보장하지 않았다. 주말·휴장일의 다음 정규장 판단도 공식 일정과 필요한 일봉의 준비를 전제로 했다.
