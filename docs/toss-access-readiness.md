# 토스 실자료 허용·조회 권한과 접근 준비

[#294](https://github.com/mochafreddo/stock-scout/issues/294)의 2026-11-07 KST 확인 기록이다. 기준은 [#278의 전환 명세](https://github.com/mochafreddo/stock-scout/issues/278#통합-전환-명세-ai-에이전트용-토스-조회-도구)와 [#283의 확정 계약](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791)이다. 계획 당시 코드 기준 `ef64daa3d663e13af8e34001609aa5da4990dcc4`에서 작업 시작 시 HEAD와 갱신한 `origin/main`은 모두 `7d6755e38552b5e9022fa7ec3d4158065c7a4d2c`로 바뀌었고, 작업 트리는 깨끗했다. 이번 변경은 접근 조건 문서와 사용 안내 연결만 다룬다.

## 현재 상태

**접근 준비는 보류 상태다.** [#284의 조사](https://github.com/mochafreddo/stock-scout/blob/bcbfd8c770bf9aa01a22807878bd8420daeae2e9/docs/research/toss-ai-data-permissions.md)에서 남은 두 질문을 공개 공식 자료로 다시 확인했으나, 실제 소비 환경에 적용되는 외부 AI 처리·보관 허용과 공급자가 강제하는 조회 전용 권한은 확정하지 못했다. 공급자의 공식 답변이나 별도 적용 계약은 이번 작업에서 확보하지 않았다. 문서 조사 종료를 #294 완료로 취급하지 않는다.

실제 토스 자료의 외부 AI 전달과 실계좌 연결은 계속 보류한다. 원자료를 요약하거나 수동으로 복사하는 방식에도 같은 조건을 적용하며, 다른 공급자를 자동 우회로로 사용하지 않는다. CLI 주문 기능 제외·IP 제한·키 로컬 관리가 공급자 조회 전용 권한을 대신하지 않는다. 이 보류는 [#283의 확정 계약](https://github.com/mochafreddo/stock-scout/issues/283#issuecomment-6686267791)을 적용한 것이며, 외부 AI 이용이 법률상 전면 금지된다는 판단은 아니다.

## 소비 환경과 처리·보관 경로

사용자는 개인 구독과 OpenAI dots 사용을 확인했다. 개인별 설정값·계좌·로컬 경로는 이 공유 문서에 기록하지 않는다. 실제 학습·환경 공유·메모리 설정과 dots의 노트북 연결 상태는 접근 승인 전에 별도로 확인해야 하며, 현재 확인 완료로 취급하지 않는다.

[OpenAI의 dots 소개](https://openai.com/ko-KR/index/introducing-dots/)는 자체 클라우드 컴퓨터·브라우저와 연결된 앱을 사용하고, 권한을 받아 노트북에도 연결할 수 있다고 설명한다. 따라서 로컬 CLI 실행을 곧바로 로컬 전용 처리·보관으로 간주하지 않는다. 이번 작업에서 실제 dots 연결을 시험하지 않았다.

[OpenAI 데이터 제어 안내](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)에 따르면 개인 계정의 `Improve the model for everyone` 설정과 Codex의 별도 `Include environments` 설정을 구분해야 한다. 학습을 꺼도 저장된 대화는 남을 수 있다. API의 보관 설정을 개인 구독 제품에 그대로 적용하지 않는다.

[dots 개인정보 FAQ](https://help.openai.com/en/articles/20001529-dots-privacy-security-and-safety-faqs)는 대화·연결 앱의 문맥이 dot을 유지하는 동안 남을 수 있고 ChatGPT 메모리와 공유될 수 있음을 설명한다. 연결 해제는 이미 문맥에 반영된 정보를 삭제하지 않으며, dot 삭제와 별도 파일·대화·ChatGPT 메모리 삭제도 구분된다. 이 FAQ의 이번 직접 수집은 HTTP 403으로 실패하여 공식 페이지를 웹 읽기 도구로 확인했다. 개인 계정의 모델 개선 설정이 dots 활동에도 적용되지만 학습 미사용이 즉시 삭제를 뜻하지는 않는다.

다음 표는 허용 판정이 아니라 공식 확인이 필요한 처리 범위다. OpenAI의 처리 정책은 토스의 자료 이용 허용을 대신하지 않는다.

| 자료 범위 | Codex·dots에 전달하려는 내용 | 확인할 처리·보관 조건 |
| --- | --- | --- |
| 시장 원자료 | 종목 정보·순위·현재가·호가·체결·일봉·분봉·일정·거래 제약 | 비공개 외부 추론, 작업·대화 기록, 운영 로그·캐시·백업, 학습 이용, 보관 기간·삭제·처리 지역·하위 처리자 |
| 계좌 원자료 | 보유·수량·평균매수가·손익·매수 가능 금액·거래내역·주문 상태. 직접 계좌 식별자·키·토큰은 CLI 출력에서 제거하여 모델 입력에 포함하지 않음 | 식별자 제거 후 금융자료 처리, 대화·dot 문맥·메모리 반영과 삭제, 연결 해제 이후 보관 |
| 시장 요약·가공 결과 | 집계 수치·등락률·추세 설명·모델 분석 | 수치·원자료 복원 가능성에 따른 파생 결과 제한과 재이용 |
| 계좌 요약·가공 결과 | 비중·집계 손익·포트폴리오 설명·모델 분석 | 사용자별 장기 문맥·메모리·대화 보관과 파생 결과 재전달 |

## 미전송 공식 문의 초안

다음은 승인 검토용 초안이며 전송하지 않았다. 수신 경로는 사용자가 선택할 토스증권 공식 고객센터의 Open API 문의 경로다. 실제 계좌·거래·자격 증명·로컬 경로는 포함하지 않는다. 소비 환경의 구체 설정이 미확인이면 그 사실을 함께 전달하고 조건별 답변을 요청한다.

> 개인 투자자가 본인 컴퓨터에서 토스 Open API 조회 CLI를 실행하고, OpenAI 개인 구독의 Codex와 ChatGPT dots에서 본인 투자 판단을 위해 결과를 해석하려 합니다. dots는 자체 클라우드 환경과 사용자가 승인한 노트북 연결을 사용할 수 있습니다. 주문 제출·정정·취소 기능은 사용하지 않으며 키·토큰과 직접 계좌 식별자는 모델에 전달하지 않는 구조입니다. 다른 투자자에게 자료나 결과를 공개·판매하려는 목적은 없습니다.
>
> 1. 이 구조에 적용되는 최신 약관·시세 이용 계약·추가 동의의 공식 주소와 적용일을 알려 주시기 바랍니다. 외부 모델이 로컬 CLI 조회를 지시하는 구조에 별도 승인·계약이 필요한지도 확인 부탁드립니다.
> 2. 시장 원자료와 계좌 원자료를 비공개 외부 모델 추론에 입력할 수 있습니까? 계좌번호 등을 제거한 보유·손익·매수 가능 금액·거래내역·주문 상태에도 각각 답변 부탁드립니다.
> 3. 시장·계좌 자료의 집계 수치·비중·등락률·자연어 요약과 모델 분석 결과에도 동일한 제한이 적용됩니까? 허용되는 가공 수준과 재전달 조건을 알려 주시기 바랍니다.
> 4. 학습 사용 여부와 별개로 대화·작업 기록, dots의 장기 문맥·ChatGPT 메모리, 로그·캐시·백업에 남을 수 있습니다. 각 저장 형태·기간·삭제 방식·처리 지역·하위 처리자에 필요한 조건과 금지 범위를 알려 주시기 바랍니다. 학습을 끈 경우와 켠 경우도 구분해 주시기 바랍니다.
> 5. 공급자가 강제하는 조회 전용 클라이언트·토큰·역할을 설정할 수 있습니까? 공식 설정 절차와 계좌별 적용 범위, 일반·조건 주문의 생성·정정·취소 차단 범위를 알려 주시기 바랍니다. IP 제한과 구분한 답변을 부탁드립니다.
> 6. 주문 요청을 전송하지 않고 해당 권한을 확인할 공식 화면·조회 API·권한 설명이 있습니까? 조회 전용 권한을 제공하지 않는다면 그 사실을 명시해 주시기 바랍니다.

## 실행별 승인 범위와 준비 순서

아래는 제안이며 실행 승인이나 준비 완료 기록이 아니다. 각 승인은 해당 작업에만 적용한다. 조회 전용 권한이 없거나 미확인이면 사용자가 제한 수용 여부를 별도로 결정할 수 있으나, 그 결정이 자료 전달 허용까지 대신하지 않는다.

| 작업 | 실행 전에 특정할 승인 범위 | 현재 결과와 재개 조건 |
| --- | --- | --- |
| 공식 문의 전송 | 위 초안의 최종 본문, 수신 경로, 소비 환경 설명의 외부 공유 범위 | 미전송. 사용자 승인 후 공식 경로로 문의하거나 사용자가 확보한 공식 답변을 검토한다. |
| 키 발급 | 조회 목적의 클라이언트, 공급자 권한·계좌 범위, 발급·약관 동의 주체 | 미수행. 조회 전용 계약 확보 또는 사용자의 명시적 제한 수용이 선행 조건이다. 어느 경우든 별도 발급 승인 후 진행한다. |

## #294 인수 조건 평가

| 조건 | 현재 평가 |
| --- | --- |
| 실제 소비 환경·자료 종류·처리·보관에 적용되는 공식 허용 확인 | 부분 확인. 공식 공개 자료와 소비 환경 정책을 재확인했지만 토스의 구체적 허용·개별 계약은 미확인이다. |
| 공급자 조회 전용 권한의 존재·설정·차단 범위 확인 | 미완료. 공개 스키마만으로 확정할 수 없으며 계정 설정·공식 답변을 확보하지 않았다. |
| 문의·키·인증·위치·계좌·전달의 승인 범위 구체화 및 사전 승인 | 부분 완료. 범위와 문의 초안은 준비했으나 실제 실행 승인은 받지 않았다. |
| 조건·승인 후 보호 위치와 별칭·기본 계좌·허용 범위 준비 | 미착수. 선행 조건과 별도 승인이 필요하다. |
| 미확인 시 전달·계좌 연결 보류 | 적용 중. 실제 자료·자격 증명 접근과 우회 전달을 수행하지 않았다. |
| 허용·권한·접근 준비 또는 명시적 재결정으로 진행 조건 확정 | 미완료. 공식 확인과 사용자 결정 후 재평가한다. #294는 완료 처리하지 않는다. |

이번 작업은 제품 코드·자료 계약·공개 검증 경계를 변경하지 않는다. 문서 내용 자체를 문자열로 고정하는 테스트는 추가하지 않으며, 문서 링크·공백 검사와 기존 로컬 품질 검사를 적용한다. 기존 테스트 통과는 토스의 허용·조회 전용 권한·실연동·소비 환경 연결 성공의 근거가 아니다.
