# 한국 낮 순위의 완료 세션 의미 조사

2026-10-26 후속 설계에서 [ADR 0011](adr/0011-ranking-discovery-and-runtime-data-readiness.md)에 따라 #249를 조회 가능 범위와 사용 제약을 정하는 조사 작업으로 조정했다. 조회 당시 순위는 탐색에만 사용하고 분석은 날짜가 확인된 KIS 일봉을 사용하는 운영 가정으로 진행한다. 고정 시각·추가 날짜 관측과 공급자 답변·페이지·정상 빈 응답 실연동을 완료 관문에서 제외한다. 이하 본문은 변경 전 조사 결과와 당시 차단·재개 조건의 기록이다. 미확인 사실은 유지하며 새 합의가 기존 관측을 데이터 의미 입증으로 바꾸지는 않는다. 런타임 구현·실제 관측·원격 이슈 완료는 별도다.

2026-10-26 [#249](https://github.com/mochafreddo/stock-scout/issues/249)의 합의한 첫 단계인 공식 자료 조사를 진행했다. **직전 완료 정규장 순위를 한국 낮에 얻는 방법은 확인하지 못했다.** 공급자의 제공 불가능을 입증한 결과는 아니다. 세션 의미가 확인되지 않아 합의한 12:00·15:00 KST 관측, 연속 페이지·빈 응답 실연동과 도구 변경은 보류한다. #249·#243 및 후속 후보군·추천의 차단은 유지한다.

## 조사 범위와 출처

Context7에서 `/koreainvestment/open-trading-api`를 찾은 뒤 공식 원본을 직접 읽었다. Context7의 후속 응답은 다른 엔드포인트의 세션 구분 예제를 반환했으므로 해당 설명을 순위 API의 의미로 채택하지 않았다. 공식 사이트 한정 검색은 결과를 얻지 못했으며 이를 문서 부재의 증거로 사용하지 않는다.

공식 저장소는 조회 당시 `main`의 커밋 `cd63caee6aeb90553d506b15ab6866cfad23beda`에 고정했다. 거래량·거래대금 개별 예제와 출력 필드 매핑, 일별 시세 예제 및 통합 예제의 두 순위 함수를 읽었다. 공식 포털은 홈에서 API 가이드로 이동하는 링크와 가이드의 공개 상세 조회 경로를 확인한 뒤 세 API의 요약·요청·응답 필드 정의를 읽었다. 포털 정의와 예제의 실제 서비스 보장 범위는 구분한다.

순위 포털의 `NDAY` 설명은 거래량 예제에 남은 “N분전콤보값”보다 구체적이지만, `1`이 직전 완료 정규장 한 세션을 뜻하는지, 여러 날 누적인지, 날짜 계산이 어느 시각에 바뀌는지는 밝히지 않는다. 따라서 `NDAY=1`을 전일 정규장 순위로 간주하지 않는다. 조회 시각이나 일부 일별 행과의 수치 일치도 전체 순위의 세션 근거로 대신하지 않는다.

## 페이지 계약의 충돌

두 순위 포털은 요청·응답 헤더의 `tr_cont`에 대해 “tr_cont를 이용한 다음조회 불가 API”라고 명시하고 `KEYB`는 공백으로 설명한다. 반면 고정한 두 예제는 응답 `tr_cont`가 `M` 또는 `F`이면 `N`으로 반복 요청한다. 거래량 예제는 기존 `keyb`를 그대로 넘기고, 거래대금 예제는 응답 최상위 `keyb`가 있으면 갱신한다. 일별 시세 포털도 `tr_cont` 다음 조회 불가를 명시하지만 요청 `KEYB`에는 다음 값을 전달하는 설명이 있다.

이는 공식 자료 사이의 충돌이며 실제 연속 조회 가능·불가능을 검증한 결과가 아니다. 기존 관측의 `continuation=F`만으로 후속 페이지가 있다고 승인하거나 공개 예제의 반복 요청을 그대로 구현하지 않는다. 세션 의미가 확인된 뒤 이 충돌을 해소할 근거와 제한된 검증 방법을 먼저 정한다. 정상 빈 응답과 계정 호출 제한도 미검증으로 유지한다.

## 확인한 한계와 재개 조건

| 항목 | 현재 판단과 다음 확인 |
| --- | --- |
| 집계 세션·초기화 시점 | 이번 자료에서 정규장 전용 집계나 날짜 전환 시점을 확인하지 못했다. 해당 정의 또는 이를 판단할 추가 관측 가설이 필요하다. |
| 완료 세션 선택 | 명시적 기준일 인수는 없고 `NDAY`의 완료 세션 대응도 미확인이다. 현재 순위 사용이나 다른 공급자로의 전환은 별도 설계 결정이다. |
| 정규장 범위·단위 | 필드 명칭만으로 시간외 포함 여부, 거래량·거래대금의 단위·배율을 확정하지 않는다. 기존 미검증을 유지한다. |
| 일별 수정주가·기간 | 포털의 선택값 정의는 확보했으나 실제 수정 반영·완료 정규장 범위는 미검증이다. 포털은 호출당 최대 100건을 안내하지만 분석에 필요한 최소 과거 기간과 동일하지 않다. 필요한 기간과 최종 운영값은 #251에서 근거를 종합한다. |
| 한국 낮 준비·예외 날짜 | 새 KIS 응답을 수집하지 않았다. 12시·15시는 관측 목표이며 지원 시간이나 두 점 사이 연속 유효성의 증거가 아니다. |

추가 관측의 가설은 `NDAY=0` 순위가 한국 낮에도 직전 완료 정규장 값을 유지한다는 것이다. 대립 가설은 한국 낮의 날짜 전환이나 진행 중인 거래를 반영해 집계가 바뀐다는 것이다. 확인 방법은 합의한 두 시점의 여섯 순위와 고정 표본 일별 행을 비교하되, 일별 첫 행 대신 공식 일정의 데이터 기준 세션 날짜에 해당하는 행을 명시적으로 선택하는 것이다. 이 시각들은 뉴욕 자정을 사이에 두지만, 그 사실만으로 공급자의 초기화 기준을 뉴욕 자정으로 가정하지 않는다.

시점 사이에 순위 표본 수치가 달라지고 완료 세션 일별 행은 같다면 고정 완료 세션 값이라는 가설에 반하는 단서로 남긴다. 정정 가능성도 있어 변화 원인을 단정하지 않는다. 두 시점 순위와 완료 세션 일별 행이 같아도 일부 표본의 대응만 확인한 것이며, 정규장 전용 집계·전체 순위의 세션이나 시간 사이 연속 유효성의 증명은 아니다. 완료 세션 행 누락이나 표본 비교 불가는 미확인으로 남긴다. `NDAY=1`의 과거 세션 의미는 이 비교만으로 확인되지 않는다.

이는 후속 검증 제안이며 기존의 세션 의미 확인 후 관측 순서를 자동 변경하지 않는다. 정의를 추가로 확보하거나 위 가설을 검증할 선행 관측 범위를 별도로 결정한 뒤 재개한다. 이번 조사에서는 추가 관측을 실행하거나 예약하지 않았으며, 공급자 문의·답변 대기나 같은 조회 반복도 추가하지 않았다.

## 선별 근거와 검증 범위

공식 포털의 공개 상세 JSON은 2026-10-26 05:34 UTC에 확보했다. 아래 해시는 당시 보존한 원본 바이트의 SHA-256이며 현재 포털 응답과 같다는 보장은 아니다. 포털의 `lastModifiedDate`는 공급자가 제공한 메타데이터로, 정의의 완전성이나 실제 적용 시점을 입증하지 않는다. 전체 원본과 수집 기록은 저장소 밖의 비공개 작업 기록에 보존한다.

이번 변경은 합의한 계획과 조사·차단 보고 문서에 한정한다. 코드·테스트·인증 경로·Actions 설정을 변경하지 않았다. 실행 로직이 없어 TDD·타입 검사·코드 형식·린트·전체 테스트·음성 대조는 생략하며, 문서 참조·변경 범위·선별 값과 원본의 일치 및 두 축 리뷰를 검증 대상으로 삼는다. #249의 낮 관측·데이터 의미·페이지·빈 응답 완료 조건은 충족하지 못했고 이슈 갱신·종료와 원격 게시는 이번 작업에 포함하지 않는다.
